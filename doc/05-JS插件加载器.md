# JS插件加载器 (JsPluginLoader)

## 模块概述

提供动态加载 JavaScript 脚本作为插件的能力，实现工具功能的可扩展性。第三方开发者可以编写 JS 脚本，无需修改主程序即可添加新功能。

## 接口定义

### 插件接口

```csharp
/// <summary>
/// JS插件接口（由JS脚本实现）
/// </summary>
public interface IJsPlugin
{
    /// <summary>插件名称（唯一标识）</summary>
    string Name { get; }

    /// <summary>插件描述</summary>
    string Description { get; }

    /// <summary>图标标识（用于UI显示）</summary>
    string Icon { get; }

    /// <summary>执行插件功能</summary>
    /// <param name="parameters">传入参数（JSON格式）</param>
    /// <returns>执行结果（JSON格式）</returns>
    Task<string> ExecuteAsync(string parameters);
}
```

### 加载器接口

```csharp
/// <summary>
/// JS插件加载器接口
/// </summary>
public interface IJsPluginLoader
{
    /// <summary>从指定目录加载所有插件</summary>
    /// <param name="pluginDirectory">插件目录路径</param>
    Task<List<IJsPlugin>> LoadPluginsAsync(string pluginDirectory);

    /// <summary>根据名称获取已加载的插件</summary>
    /// <param name="name">插件名称</param>
    IJsPlugin GetPlugin(string name);

    /// <summary>执行指定名称的插件</summary>
    /// <param name="pluginName">插件名称</param>
    /// <param name="parameters">参数（JSON字符串）</param>
    Task<string> ExecutePluginAsync(string pluginName, string parameters = "");

    /// <summary>获取所有已加载的插件列表</summary>
    List<IJsPlugin> GetLoadedPlugins();

    /// <summary>重新加载所有插件（热更新）</summary>
    Task ReloadPluginsAsync();
}
```

## JS插件规范

### 插件文件结构

```txt
Resources/Plugins/
├── weather/                    # 天气预报插件
│   ├── manifest.json           # 插件清单
│   └── main.js                 # 插件主脚本
├── compliment/                 # 夸奖插件
│   ├── manifest.json
│   └── main.js
└── timer/                      # 计时器插件
    ├── manifest.json
    └── main.js
```

### manifest.json 格式

```json
{
  "name": "weather",
  "description": "查询天气预报",
  "version": "1.0.0",
  "author": "catgirlwindow",
  "icon": "🌤️",
  "entry": "main.js",
  "permissions": ["network:http"]
}
```

### JS脚本规范

```javascript
// main.js - 插件主脚本
class Plugin {
    constructor() {
        this.name = 'weather';
        this.description = '查询天气预报';
        this.icon = '🌤️';
    }

    /**
     * 插件执行入口
     * @param {string} parameters - JSON格式参数，如 {"city": "北京"}
     * @returns {string} - JSON格式结果
     */
    async execute(parameters) {
        // 解析参数
        const params = JSON.parse(parameters);
        const city = params.city || '北京';

        // 调用天气API
        const response = await fetch(
            `https://api.weather.com/v1/weather?city=${encodeURIComponent(city)}`
        );
        const data = await response.json();

        // 返回结果
        return JSON.stringify({
            city: data.city,
            temperature: data.temp,
            condition: data.weather,
            advice: data.advice
        });
    }
}

// 导出插件实例
export default new Plugin();
```

## 执行流程

1. 应用启动或手动刷新时调用 LoadPluginsAsync() 扫描插件目录
2. 解析每个插件的 manifest.json，加载 main.js
3. 创建 JS 运行时，注册插件实例
4. 插件就绪，等待 ExecutePluginAsync() 调用

## 安全考虑

| 安全措施 | 说明 |

| 沙箱执行 | JS脚本在隔离的运行时中执行，不能访问文件系统 |
| 权限声明 | 插件必须在 manifest.json 中声明所需权限 |
| 超时控制 | 插件执行超过30秒自动终止 |
| 异常隔离 | 单个插件崩溃不影响主程序和其他插件 |

## 单元测试

### 测试要点

| 测试用例 | 预期结果 |
| ---------- | ---------- |
| 加载插件目录后返回插件列表 | LoadPluginsAsync 返回非空列表 |
| 根据名称获取已加载插件 | GetPlugin("weather") 返回对应插件实例 |
| 执行插件返回结果 | ExecutePluginAsync 返回非空 JSON 字符串 |
| 重新加载插件后列表更新 | ReloadPluginsAsync 后 GetLoadedPlugins 返回新列表 |
| 插件不存在时返回 null | GetPlugin("nonexistent") 返回 null |
| 获取所有已加载插件 | GetLoadedPlugins 返回所有已加载插件 |

### 测试方法

```csharp
[Fact]
public async Task LoadPlugins_ShouldReturnPluginList()
{
    var loader = new JsPluginLoader();
    var plugins = await loader.LoadPluginsAsync("./Resources/Plugins");
    Assert.NotEmpty(plugins);
}

[Fact]
public void GetPlugin_Existing_ShouldReturnInstance()
{
    var loader = new JsPluginLoader();
    var plugin = loader.GetPlugin("weather");
    Assert.NotNull(plugin);
    Assert.Equal("weather", plugin.Name);
}

[Fact]
public void GetPlugin_NonExisting_ShouldReturnNull()
{
    var loader = new JsPluginLoader();
    var plugin = loader.GetPlugin("nonexistent");
    Assert.Null(plugin);
}

[Fact]
public async Task ExecutePlugin_ShouldReturnResult()
{
    var loader = new JsPluginLoader();
    var result = await loader.ExecutePluginAsync("weather", "{\"city\":\"北京\"}");
    Assert.NotNull(result);
}
```

## 依赖关系
