# 自动事件服务 (AutoEventService)

## 模块概述

通用定时任务调度器，类似 Linux 的 cron。管理所有定时触发的自动行为，包括碎碎念、用眼提醒、深夜关怀等。这些行为不需要用户主动触发，由系统根据时间和用户活动状态自动执行。

**核心设计**：通用 cron 定时器 + 三个内置特殊事件（碎碎念、用眼提醒、深夜关怀）。Agent 可通过工具调用动态注册/取消定时任务。

## 定时任务模型

```csharp
/// <summary>
/// 定时任务定义
/// </summary>
public class CronTask
{
    /// <summary>任务唯一标识</summary>
    public string Id { get; set; }

    /// <summary>任务名称（描述）</summary>
    public string Name { get; set; }

    /// <summary>Cron 表达式（仅支持分钟级：* * * * *）</summary>
    public string CronExpression { get; set; }

    /// <summary>任务类型标识（如 "murmur"、"eye_rest"、"late_night"、"custom"）</summary>
    public string TaskType { get; set; }

    /// <summary>任务参数（传递给 Agent 的额外数据）</summary>
    public string? Parameters { get; set; }

    /// <summary>是否启用</summary>
    public bool Enabled { get; set; } = true;

    /// <summary>创建时间</summary>
    public DateTime CreatedAt { get; set; } = DateTime.Now;
}
```

### Cron 表达式格式

采用简化的 5 字段格式（分 时 日 月 周），与 Linux cron 一致：

```txt
┌───────── 分钟 (0-59)
│ ┌───────── 小时 (0-23)
│ │ ┌───────── 日期 (1-31)
│ │ │ ┌───────── 月份 (1-12)
│ │ │ │ ┌───────── 星期 (0-7, 0和7都表示周日)
│ │ │ │ │
* * * * *
```

**支持的特性**：

- `*` 任意值
- `,` 列表分隔（如 `1,15,30`）
- `-` 范围（如 `9-18`）
- `*/N` 步长（如 `*/30` 表示每30分钟）

**示例**：

| 表达式 | 说明 |
|--------|------|
| `*/30 * * * *` | 每30分钟执行一次 |
| `0 */2 * * *` | 每2小时的整点执行 |
| `0 9-18 * * *` | 每天9点到18点每小时整点执行 |
| `30 23 * * *` | 每天23:30执行 |
| `0 8,12,18 * * *` | 每天8点、12点、18点执行 |

## 核心接口

```csharp
/// <summary>
/// 自动事件服务接口
/// </summary>
public interface IAutoEventService
{
    /// <summary>启动定时任务调度器</summary>
    void Start();

    /// <summary>停止所有定时任务</summary>
    void Stop();

    // ========== 通用 Cron 任务管理（供 Agent 工具调用） ==========

    /// <summary>注册一个 cron 定时任务</summary>
    void RegisterTask(CronTask task);

    /// <summary>取消一个 cron 定时任务</summary>
    void UnregisterTask(string taskId);

    /// <summary>启用/禁用一个 cron 定时任务</summary>
    void SetTaskEnabled(string taskId, bool enabled);

    /// <summary>获取所有已注册的 cron 定时任务</summary>
    List<CronTask> GetAllTasks();

    /// <summary>获取指定类型的 cron 定时任务</summary>
    List<CronTask> GetTasksByType(string taskType);

    // ========== 内置事件配置 ==========

    /// <summary>设置碎碎念权重（0-100，0=禁用）</summary>
    void SetMurmurWeight(int weight);

    /// <summary>获取碎碎念权重</summary>
    int MurmurWeight { get; }

    /// <summary>设置深夜关怀偏移范围（分钟）</summary>
    /// <param name="minMinutes">最小偏移分钟数</param>
    /// <param name="maxMinutes">最大偏移分钟数</param>
    void SetLateNightOffsetRange(int minMinutes, int maxMinutes);

    /// <summary>获取深夜关怀基准时间</summary>
    TimeSpan LateNightBaseTime { get; }

    /// <summary>获取今日深夜关怀实际触发时间</summary>
    TimeSpan GetTodayLateNightTime();

    // ========== 用户活动检测 ==========

    /// <summary>记录用户活动时间（由外部调用，如鼠标/键盘事件）</summary>
    void RecordUserActivity();

    // ========== 事件 ==========

    /// <summary>定时任务触发事件（参数为触发的 CronTask）</summary>
    event EventHandler<CronTask> OnTaskTriggered;
}
```

## 三个内置事件

系统内置三个特殊事件，它们不是普通的 cron 任务，有各自的触发逻辑：

### 1. 碎碎念（Murmur）

**触发机制**：在主循环中每 10 次 tick 进行一次随机判断，通过权重控制触发概率。

| 属性 | 说明 |
| ------ | ------ |
| 触发方式 | 每10次主循环 tick，随机数判断 |
| 权重范围 | 0 ~ 100（0=永不触发，100=每次必触发） |
| 默认权重 | 30（约每10次 tick 有30%概率触发） |
| 触发内容 | 调用 LLM 生成温暖的唠叨（通过 PromptFormatter） |
| 展示方式 | 弹出气泡对话框 |
| 开关控制 | 权重设为0即禁用 |

**权重与频率关系**（假设主循环每秒 tick 一次）：

| 权重 | 约平均间隔 |
| ------ | ----------- |
| 10 | 每100秒一次 |
| 30 | 每33秒一次 |
| 50 | 每20秒一次 |
| 100 | 每10秒一次 |

**示例唠叨：**

- "记得喝水哦～"
- "坐了好久啦，起来活动一下吧！"
- "今天心情怎么样呀？"
- "想你了呢～"

### 2. 用眼提醒（Eye Rest）

**触发机制**：从程序启动时开始计时，检测用户连续使用时长。用户活动（鼠标/键盘）会重置计时器。

| 属性 | 说明 |
|------|------|
| 触发条件 | 用户连续使用电脑超过阈值无休息 |
| 计时起点 | 程序启动时开始计时（开机后设置） |
| 检测方式 | 监控用户活跃交互时间（鼠标/键盘操作） |
| 默认阈值 | 120分钟（2小时） |
| 提醒内容 | "你已经连续工作X小时了，让眼睛休息一下吧～" |
| 频率 | 每达到阈值提醒一次，用户活动后重置 |
| 情绪影响 | AI女友切换为 Sad（心疼） |

### 3. 深夜关怀（Late Night Care）

**触发机制**：内置在服务中，每天在指定时间触发，但触发时间有随机偏移。

| 属性 | 说明 |
|------|------|
| 基准时间 | 23:00（默认） |
| 偏移范围 | 默认 -30 ~ +30 分钟（即可配置偏移范围） |
| 实际触发 | 每天在基准时间 + 随机偏移量 触发 |
| 偏移重置 | 每天重新随机一次 |
| 触发条件 | 用户仍在活跃（未休眠） |
| 提醒内容 | "这么晚还不睡呀，熬夜对身体不好哦～" |
| 情绪影响 | AI女友切换为 Sleepy（困倦） |

**示例**：

- 基准时间 23:00，偏移范围 -30~+30
- 第1天实际触发时间：22:45（随机偏移 -15）
- 第2天实际触发时间：23:22（随机偏移 +22）
- 第3天实际触发时间：22:38（随机偏移 -22）

## 事件流

```
AutoEventService.Start()
    │
    ├─ 初始化三个内置事件的状态
    │   ├─ 碎碎念：计数器=0，准备随机判断
    │   ├─ 用眼提醒：记录启动时间
    │   └─ 深夜关怀：计算今日随机触发时间
    │
    └─ 启动主循环定时器（每秒 tick 一次）
         │
         ├─ [每 tick] 检查所有 cron 任务（Agent 注册的）
         │   └─ 匹配 → 触发 OnTaskTriggered
         │
         ├─ [每 10 tick] 碎碎念随机判断
         │   └─ 随机命中 → 触发 OnTaskTriggered(TaskType="murmur")
         │
         ├─ [每 tick] 用眼提醒检测
         │   └─ 连续使用超阈值 → 触发 OnTaskTriggered(TaskType="eye_rest")
         │
         └─ [每 tick] 深夜关怀检测
             └─ 到达今日随机时间 → 触发 OnTaskTriggered(TaskType="late_night")
```

**Agent 处理流程**：

1. `OnTaskTriggered` 事件触发
2. Agent 根据 `task.TaskType` 判断事件类型：
   - `"murmur"` → `PromptFormatter.BuildMurmurPrompt()` → `LlmClient.SendChatAsync()`
   - `"eye_rest"` → `PromptFormatter.BuildEyeRestPrompt()` → `LlmClient.SendChatAsync()`
   - `"late_night"` → `PromptFormatter.BuildLateNightCarePrompt()` → `LlmClient.SendChatAsync()`
   - 自定义类型 → 根据 `task.Parameters` 处理
3. 解析 LLM 返回的 actions 执行（可切换情绪等）
4. 返回 reply → UI 显示气泡

## Agent 工具调用接口

Agent 可通过以下工具调用操作定时任务：

| 工具名称 | 参数 | 说明 |
|---------|------|------|
| `add_cron_task` | `name`, `cron_expression`, `task_type`, `parameters?` | 注册新的 cron 定时任务 |
| `remove_cron_task` | `task_id` | 取消 cron 定时任务 |
| `enable_cron_task` | `task_id`, `enabled` | 启用/禁用 cron 定时任务 |
| `list_cron_tasks` | 无 | 列出所有 cron 定时任务 |
| `set_murmur_weight` | `weight` | 设置碎碎念权重 |
| `set_late_night_offset` | `min_minutes`, `max_minutes` | 设置深夜关怀偏移范围 |

**示例**（Agent 调用添加定时任务）：

```
用户："每天早上8点提醒我吃早餐"
Agent 调用：add_cron_task(name="早餐提醒", cron_expression="0 8 * * *", task_type="custom", parameters="该吃早餐啦～")
```

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| MurmurWeight | 30 | 碎碎念权重（0-100） |
| EyeRestThreshold | 120 | 用眼提醒阈值（分钟） |
| LateNightBaseHour | 23 | 深夜关怀基准小时 |
| LateNightBaseMinute | 0 | 深夜关怀基准分钟 |
| LateNightOffsetMin | -30 | 深夜关怀最小偏移（分钟） |
| LateNightOffsetMax | 30 | 深夜关怀最大偏移（分钟） |
| IdleThreshold | 5 | 判定用户离开的阈值（分钟） |

## 单元测试

### 测试要点

| 测试用例 | 预期结果 |
|---------|----------|
| Start 后初始化内置事件 | Start 后三个内置事件就绪 |
| Stop 后停止触发 | Stop 后无事件触发 |
| 注册 cron 任务 | RegisterTask 后 GetAllTasks 包含新任务 |
| 取消 cron 任务 | UnregisterTask 后任务从列表移除 |
| 启用/禁用 cron 任务 | SetTaskEnabled(id, false) 后该任务不触发 |
| Cron 表达式匹配 | 给定表达式和当前时间，判断是否匹配 |
| 碎碎念权重设置 | SetMurmurWeight(50) 后 MurmurWeight == 50 |
| 碎碎念权重0不触发 | 权重为0时永不触发 |
| 深夜关怀偏移范围 | 设置偏移后，今日触发时间在基准±范围内 |
| 深夜关怀每天不同 | 连续两天的触发时间不同（随机偏移） |
| 用眼提醒从启动计时 | 启动后连续使用超阈值触发提醒 |
| 用户活动重置用眼提醒 | RecordUserActivity 后用眼计时重置 |

### 测试方法

```csharp
[Fact]
public void Start_ShouldInitializeBuiltInEvents()
{
    var service = new AutoEventService();
    service.Start();
    Assert.True(service.MurmurWeight > 0);
    service.Stop();
}

[Fact]
public void RegisterCronTask_ShouldAddTask()
{
    var service = new AutoEventService();
    var task = new CronTask
    {
        Id = "test-1",
        Name = "测试任务",
        CronExpression = "*/5 * * * *",
        TaskType = "custom"
    };
    service.RegisterTask(task);
    Assert.Contains(service.GetAllTasks(), t => t.Id == "test-1");
}

[Fact]
public void UnregisterCronTask_ShouldRemoveTask()
{
    var service = new AutoEventService();
    var task = new CronTask
    {
        Id = "test-1",
        Name = "测试任务",
        CronExpression = "*/5 * * * *",
        TaskType = "custom"
    };
    service.RegisterTask(task);
    service.UnregisterTask("test-1");
    Assert.DoesNotContain(service.GetAllTasks(), t => t.Id == "test-1");
}

[Fact]
public void SetTaskEnabled_ShouldControlTrigger()
{
    var service = new AutoEventService();
    var task = new CronTask
    {
        Id = "test-1",
        Name = "测试任务",
        CronExpression = "* * * * *",
        TaskType = "custom"
    };
    service.RegisterTask(task);
    service.SetTaskEnabled("test-1", false);
    var updated = service.GetAllTasks().First(t => t.Id == "test-1");
    Assert.False(updated.Enabled);

[Fact]
public void SetMurmurWeight_ShouldUpdate()

    Assert.Equal(50, service.MurmurWeight);

public void MurmurWeight_Zero_ShouldDisable()

[Fact]
public void CronExpression_EveryMinute_ShouldMatch()

[Fact]
public void LateNightOffset_ShouldAffectTriggerTime()
{
    var service = new AutoEventService();
    service.SetLateNightOffsetRange(-60, 60);
    var todayTime = service.GetTodayLateNightTime();
    var baseTime = service.LateNightBaseTime;
    var diff = (todayTime - baseTime).TotalMinutes;
    Assert.InRange(diff, -60, 60);
}

[Fact]
public void LateNightTime_ShouldChangeDaily()
{
    var service = new AutoEventService();
    // 模拟不同日期，触发时间应不同
    var time1 = service.GetTodayLateNightTime();
    // 强制重新计算（模拟第二天）
    var time2 = service.GetTodayLateNightTime();
    // 同一天内应该相同（缓存）
    Assert.Equal(time1, time2);
}

[Fact]
public async Task TaskTriggered_ShouldFireEvent()
{
    var service = new AutoEventService();
    var tcs = new TaskCompletionSource<CronTask>();
    service.OnTaskTriggered += (_, task) => tcs.TrySetResult(task);

    service.RegisterTask(new CronTask
    {
        Id = "test-trigger",
        Name = "触发测试",
        CronExpression = "* * * * *",
        TaskType = "test"
    });
    service.Start();

    var result = await Task.WhenAny(tcs.Task, Task.Delay(2000));
    Assert.True(result == tcs.Task, "任务应在超时前触发");
    Assert.Equal("test", tcs.Task.Result.TaskType);
    service.Stop();
}

[Fact]
public void RecordUserActivity_ShouldResetEyeRest()
{
    var service = new AutoEventService();
    service.RecordUserActivity();
    Assert.NotNull(service);
}
```

## 依赖关系

- **依赖**: `IAgent`（通过 Agent 统一调度所有自动事件处理）
- **被依赖**: `Form1`（订阅事件展示UI）

> **架构变化**：AutoEventService 不再直接依赖 LlmClient/PromptFormatter/AgentMoodTracker。
> 所有自动事件的处理逻辑统一由 Agent 的 `ProcessAutoEventAsync()` 方法调度。
> AutoEventService 只负责定时触发事件，不负责事件的具体处理逻辑。
