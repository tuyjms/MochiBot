# 自动事件服务 (AutoEventService)

## 模块概述

管理所有定时触发的自动行为，包括碎碎念、用眼提醒、深夜关怀等。这些行为不需要用户主动触发，由系统根据时间和用户活动状态自动执行。

## 接口定义

### 核心接口

```csharp
/// <summary>
/// 自动事件服务接口
/// </summary>
public interface IAutoEventService
{
    /// <summary>启动所有定时任务</summary>
    void Start();

    /// <summary>停止所有定时任务</summary>
    void Stop();

    /// <summary>设置碎碎念间隔（分钟）</summary>
    /// <param name="minutes">间隔分钟数</param>
    void SetMurmurInterval(int minutes);

    /// <summary>启用/禁用碎碎念功能</summary>
    void EnableMurmur(bool enabled);

    /// <summary>获取碎碎念是否启用</summary>
    bool IsMurmurEnabled { get; }

    /// <summary>获取当前碎碎念间隔</summary>
    int MurmurInterval { get; }


    // ========== 事件 ==========

    /// <summary>碎碎念触发事件（参数为生成的唠叨文本）</summary>
    event EventHandler<string> OnMurmur;

    /// <summary>用眼提醒触发事件（参数为提醒文本）</summary>
    event EventHandler<string> OnEyeRestReminder;

    /// <summary>深夜关怀触发事件（参数为关怀文本）</summary>
    event EventHandler<string> OnLateNightCare;
}
```

> **注意**：AutoEventService 不再直接依赖 LlmClient/PromptFormatter。事件触发后，由订阅方（Agent）调用 `ProcessAutoEventAsync()` 统一处理。

## 自动事件详情

### 1. 碎碎念功能

| 属性 | 说明 |

| 触发条件 | 定时器到达间隔时间 |
| 默认间隔 | 30分钟 |
| 可配置范围 | 15分钟 ~ 120分钟 |
| 触发内容 | 调用 LLM 生成温暖的唠叨（通过 PromptFormatter） |
| 展示方式 | 弹出气泡对话框 |
| 开关控制 | 用户可在设置中开启/关闭 |

**示例唠叨：**

- "记得喝水哦～"
- "坐了好久啦，起来活动一下吧！"
- "今天心情怎么样呀？"
- "想你了呢～"

### 2. 用眼提醒

| 属性 | 说明 |

| 触发条件 | 用户连续使用电脑超过2小时无休息 |
| 检测方式 | 监控用户活跃交互时间（鼠标/键盘操作） |
| 提醒内容 | "你已经连续工作X小时了，让眼睛休息一下吧～" |
| 频率 | 每2小时提醒一次，直到用户休息 |
| 情绪影响 | AI女友切换为 Sad（心疼） |

### 3. 深夜关怀

| 属性 | 说明 |

| 触发条件 | 当前时间在 23:00 ~ 06:00 之间，且用户仍在活跃 |
| 检测方式 | 系统时间判断 + 用户活跃检测 |
| 提醒内容 | "这么晚还不睡呀，熬夜对身体不好哦～" |
| 频率 | 每30分钟提醒一次 |
| 情绪影响 | AI女友切换为 Sleepy（困倦） |

## 事件流

AutoEventService.Start() 启动三个定时器：碎碎念、用眼检测、深夜检测。

**碎碎念触发流程**：

1. 碎碎念定时器到达
2. OnMurmur 事件触发
3. Agent.ProcessAutoEventAsync("murmur", null) 被调用
4. Agent 内部：PromptFormatter.BuildMurmurPrompt() → LlmClient.SendChatAsync() 对话模式 → 解析 actions 执行（可切换情绪等）
5. 返回 reply → UI 显示气泡

**用眼提醒触发流程**：

1. 用眼检测触发（用户连续使用超过2小时）
2. OnEyeRestReminder 事件触发
3. Agent.ProcessAutoEventAsync("eye_rest", "2") 被调用
4. Agent 内部：PromptFormatter.BuildEyeRestPrompt() → LlmClient.SendChatAsync() 对话模式 → 解析 actions 执行（切换情绪为Sad等）
5. 返回提醒文本 → UI 显示

**深夜关怀触发流程**：

1. 深夜检测触发（当前时间 23:00~06:00，用户活跃）
2. OnLateNightCare 事件触发
3. Agent.ProcessAutoEventAsync("late_night", null) 被调用
4. Agent 内部：PromptFormatter.BuildLateNightCarePrompt() → LlmClient.SendChatAsync() 对话模式 → 解析 actions 执行（切换情绪为Sleepy等）
5. 返回关怀文本 → UI 显示

## 配置参数

| 参数 | 默认值 | 说明 |

| MurmurInterval | 30 | 碎碎念间隔（分钟） |
| MurmurEnabled | true | 碎碎念开关 |
| EyeRestInterval | 120 | 用眼提醒间隔（分钟） |
| LateNightStart | 23:00 | 深夜关怀开始时间 |
| LateNightEnd | 06:00 | 深夜关怀结束时间 |
| IdleThreshold | 5 | 判定用户离开的阈值（分钟） |

## 单元测试

### 测试要点

| 测试用例 | 预期结果 |
|----------|----------|
| Start 后碎碎念定时器启动 | Start 后 IsMurmurEnabled 为 true |
| Stop 后所有定时器停止 | Stop 后无事件触发 |
| 设置碎碎念间隔 | SetMurmurInterval(60) 后 MurmurInterval == 60 |
| 禁用碎碎念后不触发 | EnableMurmur(false) 后 IsMurmurEnabled 为 false |
| 碎碎念事件触发 | OnMurmur 事件在定时器到达时触发 |
| 用眼提醒事件触发 | OnEyeRestReminder 在用户连续使用超时时触发 |
| 深夜关怀事件触发 | OnLateNightCare 在深夜时段触发 |

### 测试方法

```csharp
[Fact]
public void Start_ShouldEnableMurmur()
{
    var service = new AutoEventService();
    service.Start();
    Assert.True(service.IsMurmurEnabled);
    service.Stop();
}

[Fact]
public void Stop_ShouldDisableAllTimers()
{
    var service = new AutoEventService();
    service.Start();
    service.Stop();
    // 停止后无事件触发
}

[Fact]
public void SetMurmurInterval_ShouldUpdate()
{
    var service = new AutoEventService();
    service.SetMurmurInterval(60);
    Assert.Equal(60, service.MurmurInterval);
}

[Fact]
public void EnableMurmur_False_ShouldDisable()
{
    var service = new AutoEventService();
    service.EnableMurmur(false);
    Assert.False(service.IsMurmurEnabled);
}

[Fact]
public async Task MurmurEvent_ShouldFire()
{
    var service = new AutoEventService();
    var tcs = new TaskCompletionSource<string>();
    service.OnMurmur += (_, msg) => tcs.TrySetResult(msg);
    service.Start();
    // 等待碎碎念触发（需配置短间隔测试）
    var result = await Task.WhenAny(tcs.Task, Task.Delay(5000));
    Assert.True(result == tcs.Task, "碎碎念事件应在超时前触发");
    service.Stop();
}
```

## 依赖关系

- **依赖**: `IAgent`（通过 Agent 统一调度所有自动事件处理）
- **被依赖**: `Form1`（订阅事件展示UI）

> **架构变化**：AutoEventService 不再直接依赖 LlmClient/PromptFormatter/AgentMoodTracker。
> 所有自动事件的处理逻辑统一由 Agent 的 `ProcessAutoEventAsync()` 方法调度。
> AutoEventService 只负责定时触发事件，不负责事件的具体处理逻辑。
