# 工具功能服务 (ToolService)

## 模块概述

管理所有工具功能，包括计时器、随机夸奖、摸摸她、天气预报等。工具功能通过圆形菜单（外围圆形）展示，用户点击后触发对应功能。

每个工具按 MCP 标准定义，包含名称、描述、输入参数 schema，供 LLM 理解如何调用。

## 工具定义（MCP 标准）

```csharp
/// <summary>
/// 工具定义，按 MCP 标准描述工具信息
/// </summary>
public class ToolDefinition
{
    /// <summary>工具名称（唯一标识，供LLM调用时使用）</summary>
    public string Name { get; set; } = string.Empty;

    /// <summary>工具描述（供LLM理解工具用途）</summary>
    public string Description { get; set; } = string.Empty;

    /// <summary>输入参数 schema（JSON Schema 格式，描述参数结构）</summary>
    public Dictionary<string, object> InputSchema { get; set; } = new();
}

/// <summary>
/// 工具执行结果
/// </summary>
public class ToolResult
{
    /// <summary>是否成功</summary>
    public bool Success { get; set; }

    /// <summary>结果数据（JSON格式）</summary>
    public string Data { get; set; } = string.Empty;

    /// <summary>错误信息（失败时）</summary>
    public string? Error { get; set; }
}
```

## 核心接口

```csharp
/// <summary>
/// 工具功能服务接口
/// </summary>
public interface IToolService
{
    /// <summary>获取所有已注册的基础工具定义（供LLM理解可用工具）</summary>
    List<ToolDefinition> GetToolDefinitions();

    /// <summary>根据当前情绪获取附加工具定义</summary>
    /// <param name="currentMood">当前情绪</param>
    List<ToolDefinition> GetMoodBasedTools(AgentMood currentMood);

    /// <summary>列出所有已加载的JS插件及其描述（供LLM通过 list_plugins 调用）</summary>
    Task<List<ToolDefinition>> ListPluginsAsync();

    /// <summary>执行指定工具</summary>
    /// <param name="toolName">工具名称</param>
    /// <param name="parameters">参数（JSON字符串）</param>
    Task<ToolResult> ExecuteToolAsync(string toolName, string parameters);

    // ========== 计时器 ==========

    /// <summary>启动倒计时</summary>
    Task StartTimerAsync(int seconds, Action onComplete);

    /// <summary>停止当前计时器</summary>
    void StopTimer();

    /// <summary>暂停/恢复计时器</summary>
    void TogglePauseTimer();

    /// <summary>获取计时器剩余时间（秒）</summary>
    int GetTimerRemaining();

    /// <summary>获取计时器状态</summary>
    TimerStatus GetTimerStatus();


    // ========== 随机夸奖 ==========

    /// <summary>获取一句随机夸奖</summary>
    Task<string> GetRandomComplimentAsync();


    // ========== 摸摸她 ==========

    /// <summary>执行摸摸头交互</summary>
    Task<string> PetAsync();


    // ========== 天气预报 ==========

    /// <summary>查询指定城市的天气</summary>
    Task<WeatherInfo> GetWeatherAsync(string city = "");
}
```

## 工具功能详情

### 1. 计时器

- **触发方式**：用户选择时间后点击开始
- **可选时间**：1分钟 / 5分钟 / 10分钟 / 15分钟 / 30分钟 / 自定义
- **结束提醒**：倒计时结束弹出提醒框，AI女友说提醒语
- **状态显示**：圆形菜单上显示剩余时间

### 2. 随机夸奖

- **触发方式**：点击"随机夸奖"工具
- **实现方式**：调用 LLM 生成夸奖语（通过 PromptFormatter）
- **展示方式**：弹出气泡对话框显示夸奖内容
- **情绪影响**：用户被夸奖 → 无情绪变化；AI女友 → Happy

### 3. 摸摸她

- **触发方式**：点击"摸摸她"工具
- **动画效果**：头像上方出现抚摸的手动画
- **情绪影响**：AI女友情绪切换为 Touched（感动）
- **回复**：AI女友说"抱抱你～"等回应

### 4. 天气预报

- **触发方式**：点击"天气预报"工具
- **数据来源**：调用天气 API（可通过 JS 插件实现）
- **展示内容**：城市、当前温度、天气状况、今日高低温、建议
- **自动定位**：默认通过 IP 定位城市

## 事件流

用户点击工具图标后，圆形菜单点击事件识别工具类型，执行对应功能：

- **计时器**：StartTimerAsync() → 倒计时 → 完成回调
- **夸奖**：GetRandomComplimentAsync() → PromptFormatter 格式化夸奖模板 → LlmClient.SendChatAsync() → 返回夸奖语
- **摸摸**：PetAsync() → AgentMoodTracker.SetMood(Touched) + 2dRenderer.PlayAnimation("pet_head")
- **天气**：GetWeatherAsync() → JsPluginLoader.ExecutePluginAsync("weather")

## 心情附加工具

| Happy | dance | 和AI女友一起跳舞，她会更开心 |
| Sleepy | tuck_in | 给AI女友盖好被子，哄她睡觉 |
| Touched | cuddle | 和AI女友依偎在一起 |

## 插件工具与 MCP 服务器工具查询

JS 插件和用户额外注册的 MCP 服务器工具（如电商MCP、新闻MCP）使用完全相同的动态加载机制，不直接注入 system prompt，而是通过基础工具 `list_plugins` 间接获取：

```csharp
// list_plugins 工具定义（作为基础工具注入）
new ToolDefinition
{
    Name = "list_plugins",
    Description = "列出所有已加载的JS插件和MCP服务器工具及其描述，根据返回的信息决定是否调用",
    InputSchema = new Dictionary<string, object>
    {
        { "type", "object" },
        { "properties", new Dictionary<string, object>() },
        { "required", new string[] { } }
    }
}
```

LLM 调用流程：

1. LLM 调用 `list_plugins` 获取插件和 MCP 工具列表
2. 返回 JSON 格式的列表，包含 JS 插件和 MCP 服务器工具的名称、描述、参数
3. LLM 根据描述决定是否调用某个插件或 MCP 工具
4. JS 插件通过 `plugin_call` action 执行，MCP 工具通过 `mcp_call` action 执行

### list_plugins 返回格式

```json
{
  "plugins": [
    {"type": "js_plugin", "name": "weather", "description": "查询天气预报", "parameters": {"city": "string"}},
    {"type": "js_plugin", "name": "timer", "description": "设置倒计时", "parameters": {"seconds": "number"}}
  ],
  "mcp_tools": [
    {"type": "mcp_tool", "name": "search_products", "description": "搜索电商商品（电商MCP）", "parameters": {"keyword": "string", "page": "number"}},
    {"type": "mcp_tool", "name": "get_news", "description": "获取最新新闻（新闻MCP）", "parameters": {"category": "string"}}
  ]
}
```

### 调用方式

```json
{
  "reply": "我帮你查一下最新的科技新闻～",
  "actions": [
    {"type": "mcp_call", "server": "news_mcp", "name": "get_news", "parameters": {"category": "technology"}}
  ]
}
```

## LLM 工具调用集成

Agent 在构建对话 prompt 时，按三层结构动态注入工具描述：

```csharp
// Agent 构建工具描述
var toolDescriptions = string.Join("\n", _toolService.GetToolDefinitions().Select(t =>
    $"- {t.Name}: {t.Description} (参数: {JsonSerializer.Serialize(t.InputSchema)})"
));

// 注入到 system prompt
var systemPrompt = formatter.Format(new Dictionary<string, string>
{
    { "Tools", toolDescriptions }
});
```

LLM 在回复中通过 actions 数组调用工具：

```json
{
  "reply": "好的，我帮你设置一个5分钟的倒计时～",
  "actions": [
    {"type": "tool_call", "name": "timer", "parameters": {"seconds": 300}}
  ]
}
```

## 单元测试

### 测试要点

| 测试用例 | 预期结果 |
| ---------- | ---------- |
| 获取基础工具定义列表 | GetToolDefinitions 返回包含 timer/compliment/pet/weather 的列表 |
| 根据情绪获取附加工具 | GetMoodBasedTools(Sad) 返回包含 hug 的列表 |
| 情绪为 Neutral 时无附加工具 | GetMoodBasedTools(Neutral) 返回空列表 |
| 启动计时器后状态为 Running | StartTimerAsync 后 GetTimerStatus == Running |
| 停止计时器后状态为 Idle | StopTimer 后 GetTimerStatus == Idle |
| 获取随机夸奖返回非空 | GetRandomComplimentAsync 返回非空字符串 |
| 执行摸摸后情绪变化 | PetAsync 后情绪切换为 Touched |
| 查询天气返回有效数据 | GetWeatherAsync("北京") 返回非空 WeatherInfo |
| 执行不存在的工具返回错误 | ExecuteToolAsync("nonexistent", "") 返回 Success=false |

### 测试方法

```csharp
[Fact]
public void GetToolDefinitions_ShouldReturnBaseTools()
{
    var service = new ToolService();
    var tools = service.GetToolDefinitions();
    Assert.Contains(tools, t => t.Name == "timer");
    Assert.Contains(tools, t => t.Name == "compliment");
    Assert.Contains(tools, t => t.Name == "pet");
    Assert.Contains(tools, t => t.Name == "weather");
}

[Fact]
public void GetMoodBasedTools_Sad_ShouldIncludeHug()
{
    var service = new ToolService();
    var tools = service.GetMoodBasedTools(AgentMood.Sad);
    Assert.Contains(tools, t => t.Name == "hug");
}

[Fact]
public void GetMoodBasedTools_Neutral_ShouldBeEmpty()
{
    var service = new ToolService();
    var tools = service.GetMoodBasedTools(AgentMood.Neutral);
    Assert.Empty(tools);
}

[Fact]
public async Task StartTimer_ShouldSetStatusRunning()
{
    var service = new ToolService();
    await service.StartTimerAsync(60, () => { });
    Assert.Equal(TimerStatus.Running, service.GetTimerStatus());
    service.StopTimer();
}

[Fact]
public async Task GetRandomCompliment_ShouldReturnNonEmpty()
{
    var service = new ToolService();
    var compliment = await service.GetRandomComplimentAsync();
    Assert.False(string.IsNullOrEmpty(compliment));
}

[Fact]
public async Task ExecuteTool_NonExisting_ShouldReturnFailure()
{
    var service = new ToolService();
    var result = await service.ExecuteToolAsync("nonexistent", "");
    Assert.False(result.Success);
}
```
