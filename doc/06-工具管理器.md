# 工具管理器 (ToolManager)

## 模块概述

工具管理器是**所有工具的统一点度中心**，统一管理基础工具、心情特色工具、MCP工具和JS注册工具。Agent 通过 ToolManager 执行所有工具调用，ToolManager 根据工具类型路由到对应的执行器。

## 工具分类

| 工具类型 | 说明 | 示例 |
|---------|------|------|
| 基础工具 | 内置的固定工具，直接注入 system prompt | timer, compliment, pet, weather, list_plugins, reply |
| 心情特色工具 | 根据当前情绪动态注入的附加工具 | hug(Sad), dance(Happy), tuck_in(Sleepy), cuddle(Touched), calm_down(Angry) |
| MCP工具 | 通过MCP服务器注册的外部工具 | search_products, get_news 等 |
| JS注册工具 | 通过JS插件加载器注册的工具 | 用户自定义的JS插件 |

## 工具定义（MCP 标准）

```csharp
/// <summary>
/// 工具定义，按 MCP 标准描述工具信息
/// </summary>
public class ToolDefinition
{
    /// <summary>工具名称（唯一标识，供LLM调用时使用）</summary>
    public string Name { get; set; } = string.Empty;

    /// <summary>工具描述（供LLM理解工具用途）</summary>
    public string Description { get; set; } = string.Empty;

    /// <summary>输入参数 schema（JSON Schema 格式，描述参数结构）</summary>
    public Dictionary<string, object> InputSchema { get; set; } = new();
}

/// <summary>
/// 工具执行结果
/// </summary>
public class ToolResult
{
    /// <summary>是否成功</summary>
    public bool Success { get; set; }

    /// <summary>结果数据（JSON格式）</summary>
    public string Data { get; set; } = string.Empty;

    /// <summary>错误信息（失败时）</summary>
    public string? Error { get; set; }
}
```

## 核心接口

```csharp
/// <summary>
/// 工具管理器接口
/// </summary>
public interface IToolManager
{
    /// <summary>获取所有已注册的基础工具定义（供LLM理解可用工具）</summary>
    List<ToolDefinition> GetToolDefinitions();

    /// <summary>根据当前情绪获取附加工具定义</summary>
    List<ToolDefinition> GetMoodBasedTools(AgentMood currentMood);

    /// <summary>列出所有已加载的JS插件和MCP工具（供LLM通过 list_plugins 调用）</summary>
    Task<List<ToolDefinition>> ListExternalToolsAsync();

    /// <summary>执行指定工具</summary>
    /// <param name="toolName">工具名称</param>
    /// <param name="parameters">参数（JSON字符串）</param>
    Task<ToolResult> ExecuteToolAsync(string toolName, string parameters);

    /// <summary>注册一个外部工具（由MCP服务或JS插件调用）</summary>
    void RegisterExternalTool(ToolDefinition tool, Func<string, Task<ToolResult>> executor);

    /// <summary>注销一个外部工具</summary>
    void UnregisterExternalTool(string toolName);
}
```

## 内置工具列表

### 1. 计时器 (timer)

启动一个倒计时，倒计时结束后会提醒用户。

| 属性 | 说明 |
|------|------|
| 参数 | seconds: 倒计时秒数（10-3600） |
| 状态 | Idle / Running / Paused / Completed |
| 功能 | 启动/停止/暂停/恢复/查询剩余时间 |

### 2. 随机夸奖 (compliment)

随机说一句夸奖用户的话，让用户感到被鼓励和温暖。

| 属性 | 说明 |
|------|------|
| 参数 | 无 |
| 实现 | 优先调用 LLM 生成，失败时使用本地模板 |
| 情绪影响 | 无 |

### 3. 摸摸她 (pet)

摸摸AI女友的头，她会感到开心和感动。

| 属性 | 说明 |
|------|------|
| 参数 | 无 |
| 情绪影响 | 切换为 Touched |
| 动画 | 播放 pet_head 动画 |

### 4. 天气预报 (weather)

查询指定城市的当前天气和今日天气预报。

| 属性 | 说明 |
|------|------|
| 参数 | city: 城市名称（可选，为空则自动定位） |
| 数据 | 城市、当前温度、天气状况、今日高低温、建议 |

### 5. 列出外部工具 (list_plugins)

列出所有已加载的JS插件和MCP服务器工具及其描述。

| 属性 | 说明 |
|------|------|
| 参数 | 无 |
| 返回 | JS插件列表 + MCP工具列表 |

### 6. 回复 (reply)

回复用户说的话。如果不调用此工具，则表示不回复（保持沉默）。

| 属性 | 说明 |
|------|------|
| 参数 | reply_text: 要回复的内容 |
| 说明 | 这是LLM回复用户的唯一方式 |

## 心情特色工具

根据当前情绪状态，动态注入附加工具：

| 情绪 | 附加工具 | 描述 | 情绪影响 |
|------|---------|------|---------|
| Sad | hug | 拥抱AI女友，她会感到温暖和安慰 | 切换为 Touched |
| Happy | dance | 和AI女友一起跳舞，她会更开心 | 保持 Happy |
| Sleepy | tuck_in | 给AI女友盖好被子，哄她睡觉 | 保持 Sleepy |
| Touched | cuddle | 和AI女友依偎在一起 | 保持 Touched |
| Angry | calm_down | 安抚生气的AI女友 | 切换为 Neutral |

## 工具执行流程

```
Agent 解析 LLM 响应中的 actions
        │
        ▼
ToolManager.ExecuteToolAsync(toolName, parameters)
        │
        ├── 基础工具 → 内置执行逻辑
        │   ├── timer → 启动/停止/暂停计时器
        │   ├── compliment → 生成夸奖语
        │   ├── pet → 切换情绪 + 播放动画
        │   ├── weather → 查询天气
        │   ├── list_plugins → 列出外部工具
        │   └── reply → 提取回复文本
        │
        ├── 心情特色工具 → 内置执行逻辑
        │   ├── hug → 切换情绪 + 返回回应
        │   ├── dance → 切换情绪 + 返回回应
        │   ├── tuck_in → 切换情绪 + 返回回应
        │   ├── cuddle → 切换情绪 + 返回回应
        │   └── calm_down → 切换情绪 + 返回回应
        │
        ├── MCP工具 → 路由到 MCP 服务管理
        │   └── 通过 MCP 客户端调用远程工具
        │
        └── JS注册工具 → 路由到 JS 插件加载器
            └── 通过 JS 运行时执行插件代码
```

## LLM 工具调用集成

Agent 在构建对话 prompt 时，按三层结构动态注入工具描述：

```csharp
// 第一层：基础工具（含 list_plugins）
var baseTools = _toolManager.GetToolDefinitions();

// 第二层：心情附加工具
var moodTools = _toolManager.GetMoodBasedTools(_moodTracker.CurrentMood);

// 第三层：插件/MCP工具（通过 list_plugins 间接获取）
// LLM 需要先调用 list_plugins 获取列表
```

LLM 在回复中通过 actions 数组调用工具：

```json
{
  "reply": "好的，我帮你设置一个5分钟的倒计时～",
  "actions": [
    {"type": "tool_call", "name": "timer", "parameters": {"seconds": 300}}
  ]
}
```

## 外部工具注册

MCP 服务和 JS 插件可以通过 ToolManager 注册外部工具：

```csharp
// MCP 服务注册工具
_toolManager.RegisterExternalTool(
    new ToolDefinition
    {
        Name = "search_products",
        Description = "搜索电商商品",
        InputSchema = new Dictionary<string, object>
        {
            { "type", "object" },
            { "properties", new Dictionary<string, object>
                {
                    { "keyword", new Dictionary<string, object>
                        {
                            { "type", "string" },
                            { "description", "搜索关键词" }
                        }
                    }
                }
            },
            { "required", new[] { "keyword" } }
        }
    },
    async (parameters) => {
        // 调用 MCP 服务器
        return await _mcpClient.CallToolAsync("search_products", parameters);
    }
);
```

## 依赖关系

- **依赖**: `LlmClient`（夸奖功能）、`AgentMoodTracker`（情绪切换）、`IJsPluginLoader`（JS插件）、`IMcpService`（MCP工具）
- **被依赖**: `Agent`（通过 Agent 统一调度工具调用）

## 单元测试要求

| 测试用例 | 预期结果 |
|---------|----------|
| 获取基础工具定义列表 | GetToolDefinitions 返回包含 timer/compliment/pet/weather 的列表 |
| 根据情绪获取附加工具 | GetMoodBasedTools(Sad) 返回包含 hug 的列表 |
| 情绪为 Neutral 时无附加工具 | GetMoodBasedTools(Neutral) 返回空列表 |
| 执行基础工具返回正确结果 | ExecuteToolAsync("timer", {"seconds": 60}) 返回成功 |
| 执行心情工具切换情绪 | ExecuteToolAsync("hug", "") 后情绪切换为 Touched |
| 注册外部工具后可用 | RegisterExternalTool 后 GetToolDefinitions 包含新工具 |
| 注销外部工具后移除 | UnregisterExternalTool 后工具从列表移除 |
| 执行不存在的工具返回错误 | ExecuteToolAsync("nonexistent", "") 返回 Success=false |
| 列出外部工具返回列表 | ListExternalToolsAsync 返回已注册的外部工具列表 |
