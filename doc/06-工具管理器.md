# 工具管理器 (ToolService)

## 模块概述

工具管理器是**所有工具的统一点度中心**，统一管理基础工具、心情特色工具、MCP工具和DLLMOD插件。Agent 通过 ToolService 执行所有工具调用，ToolService 根据工具类型路由到对应的执行器。

## 工具分类

| 工具类型 | 说明 | 示例 |
|---------|------|------|
| 基础工具 | 内置的固定工具，直接注入 system prompt | timer, list_plugins, reply |
| 心情特色工具 | 根据当前情绪动态注入的附加工具 | cry(Sad), dance(Happy), yawn(Sleepy), blush(Touched), stomp(Angry) |
| MCP工具 | 通过MCP服务器注册的外部工具 | search_products, get_news 等 |
| DLLMOD插件 | 通过DLLMOD加载器注册的工具 | 用户自定义的DLL插件 |

## 心情特色工具

根据当前情绪状态，动态注入附加工具。**注意：心情特色工具只播放动画，不涉及任何情绪变化**。情绪变化由 Agent 内部根据用户消息内容自动检测触发，或由 LLM 通过 `mood_change` action 主动切换。

| 情绪 | 附加工具 | 描述 | 效果 |
|------|---------|------|------|
| Sad | cry | 播放哭泣动画，表达委屈难过的情绪 | 播放 cry 动画 |
| Happy | dance | 播放跳舞动画，表达开心愉悦的情绪 | 播放 dance 动画 |
| Sleepy | yawn | 播放打哈欠动画，表达困倦想睡的情绪 | 播放 yawn 动画 |
| Touched | blush | 播放脸红动画，表达害羞感动的情绪 | 播放 blush 动画 |
| Angry | stomp | 播放跺脚动画，表达生气不满的情绪 | 播放 stomp 动画 |

## 工具执行流程

```
Agent 解析 LLM 响应中的 actions
        │
        ├── tool_call → ToolService.ExecuteToolAsync(toolName, parameters)
        │
        ├── plugin_call → 路由到 DLLMOD 加载器
        │
        └── mcp_call → 路由到 MCP 服务管理
```

## 情绪变化流程

情绪变化不由 ToolService 触发（ToolService 作为基建不关心情绪），而是通过以下两种方式：

1. **LLM 主动切换**：LLM 在 actions 中返回 `mood_change` action，Agent 的 `ExecuteActionsAsync` 方法解析并调用 `SetMood()` 切换情绪。
2. **Agent 自动检测**：Agent 在 `ProcessUserInputAsync` 中根据用户消息内容（如"摸摸"、"夸"等关键词）和时间（深夜）自动调用 `UpdateMoodByEvent()` 切换情绪。


## LLM 工具调用集成

Agent 在构建对话 prompt 时，按三层结构动态注入工具描述：

```csharp
// 第一层：基础工具（含 list_plugins）
var baseTools = _toolManager.GetToolDefinitions();

// 第二层：心情附加工具
var moodTools = _toolManager.GetMoodBasedTools(_agent.CurrentMood);

// 第三层：DLLMOD/MCP工具（通过 list_plugins 间接获取）
// list_plugins会通过事件的方式把外部工具放入LLM上下文
```

## 依赖关系

- **依赖**: `LlmClient`（夸奖功能）、`IPromptFormatter`（Prompt格式化）
- **不依赖**: `IAgentMoodTracker`（情绪变化通过 LLM 的 mood_change action 走统一事件调度）
- **被依赖**: `Agent`（通过 Agent 统一调度工具调用）

## 单元测试要求

| 测试用例 | 预期结果 |
|---------|----------|
| 获取基础工具定义列表 | GetToolDefinitions 返回 列表 |
| 根据情绪获取附加工具 | GetMoodBasedTools(Sad) 返回包含 cry 的列表 |
| 情绪为 Neutral 时无附加工具 | GetMoodBasedTools(Neutral) 返回空列表 |
| 执行基础工具返回正确结果 | ExecuteToolAsync("timer", {"seconds": 60}) 返回成功 |
| 执行心情工具只播放动画 | ExecuteToolAsync("cry", "") 返回 animation 结果，不涉及情绪变化 |
| 注册外部工具后可用 | RegisterExternalTool 后 GetToolDefinitions 包含新工具 |
| 注销外部工具后移除 | UnregisterExternalTool 后工具从列表移除 |
| 执行不存在的工具返回错误 | ExecuteToolAsync("nonexistent", "") 返回 Success=false |
| 列出外部工具返回列表 | ListExternalToolsAsync 返回已注册的外部工具列表 |
