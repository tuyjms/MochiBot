# 工具管理器 (ToolManager)

## 模块概述

工具管理器是**所有工具的统一点度中心**，统一管理基础工具、心情特色工具、MCP工具和DLLMOD插件。Agent 通过 ToolManager 执行所有工具调用，ToolManager 根据工具类型路由到对应的执行器。

## 工具分类

| 工具类型 | 说明 | 示例 |
|---------|------|------|
| 基础工具 | 内置的固定工具，直接注入 system prompt | timer, compliment, pet, weather, list_plugins, reply |
| 心情特色工具 | 根据当前情绪动态注入的附加工具 | cry(Sad), dance(Happy), yawn(Sleepy), blush(Touched), stomp(Angry) |
| MCP工具 | 通过MCP服务器注册的外部工具 | search_products, get_news 等 |
| DLLMOD插件 | 通过DLLMOD加载器注册的工具 | 用户自定义的DLL插件 |

## 工具定义（MCP 标准）

```csharp
/// <summary>
/// 工具定义，按 MCP 标准描述工具信息
/// </summary>
public class ToolDefinition
{
    /// <summary>工具名称（唯一标识，供LLM调用时使用）</summary>
    public string Name { get; set; } = string.Empty;

    /// <summary>工具描述（供LLM理解工具用途）</summary>
    public string Description { get; set; } = string.Empty;

    /// <summary>输入参数 schema（JSON Schema 格式，描述参数结构）</summary>
    public Dictionary<string, object> InputSchema { get; set; } = new();
}

/// <summary>
/// 工具执行结果
/// </summary>
public class ToolResult
{
    /// <summary>是否成功</summary>
    public bool Success { get; set; }

    /// <summary>结果数据（JSON格式）</summary>
    public string Data { get; set; } = string.Empty;

    /// <summary>错误信息（失败时）</summary>
    public string? Error { get; set; }
}
```

## 核心接口

```csharp
/// <summary>
/// 工具管理器接口
/// </summary>
public interface IToolManager
{
    /// <summary>获取所有已注册的基础工具定义（供LLM理解可用工具）</summary>
    List<ToolDefinition> GetToolDefinitions();

    /// <summary>根据当前情绪获取附加工具定义</summary>
    List<ToolDefinition> GetMoodBasedTools(AgentMood currentMood);

    /// <summary>列出所有已加载的DLLMOD和MCP工具（供LLM通过 list_plugins 调用）</summary>
    Task<List<ToolDefinition>> ListExternalToolsAsync();

    /// <summary>执行指定工具</summary>
    /// <param name="toolName">工具名称</param>
    /// <param name="parameters">参数（JSON字符串）</param>
    Task<ToolResult> ExecuteToolAsync(string toolName, string parameters);

    /// <summary>注册一个外部工具（由MCP服务或DLLMOD调用）</summary>
    void RegisterExternalTool(ToolDefinition tool, Func<string, Task<ToolResult>> executor);

    /// <summary>注销一个外部工具</summary>
    void UnregisterExternalTool(string toolName);
}
```

## 内置工具列表

### 1. 计时器 (timer)

启动一个倒计时，倒计时结束后会提醒用户。

| 属性 | 说明 |
|------|------|
| 参数 | seconds: 倒计时秒数（10-3600） |
| 状态 | Idle / Running / Paused / Completed |
| 功能 | 启动/停止/暂停/恢复/查询剩余时间 |

### 2. 随机夸奖 (compliment)

随机说一句夸奖用户的话，让用户感到被鼓励和温暖。

| 属性 | 说明 |
|------|------|
| 参数 | 无 |
| 实现 | 优先调用 LLM 生成，失败时使用本地模板 |
| 情绪影响 | 无（情绪变化由 LLM 的 mood_change action 处理） |

### 3. 摸摸她 (pet)

摸摸AI女友的头，她会感到开心和感动。

| 属性 | 说明 |
|------|------|
| 参数 | 无 |
| 情绪影响 | 无（情绪变化由 LLM 的 mood_change action 处理） |
| 动画 | 播放 pet_head 动画 |

### 4. 天气预报 (weather)

查询指定城市的当前天气和今日天气预报。

| 属性 | 说明 |
|------|------|
| 参数 | city: 城市名称（可选，为空则自动定位） |
| 数据 | 城市、当前温度、天气状况、今日高低温、建议 |

### 5. 列出外部工具 (list_plugins)

列出所有已加载的DLLMOD插件和MCP服务器工具及其描述。

| 属性 | 说明 |
|------|------|
| 参数 | 无 |
| 返回 | DLLMOD插件列表 + MCP工具列表 |

### 6. 回复 (reply)

回复用户说的话。如果不调用此工具，则表示不回复（保持沉默）。

| 属性 | 说明 |
|------|------|
| 参数 | reply_text: 要回复的内容 |
| 说明 | 这是LLM回复用户的唯一方式 |

## 心情特色工具

根据当前情绪状态，动态注入附加工具。**注意：心情特色工具只播放动画，不涉及任何情绪变化**。情绪变化由 Agent 内部根据用户消息内容自动检测触发，或由 LLM 通过 `mood_change` action 主动切换。

| 情绪 | 附加工具 | 描述 | 效果 |
|------|---------|------|------|
| Sad | cry | 播放哭泣动画，表达委屈难过的情绪 | 播放 cry 动画 |
| Happy | dance | 播放跳舞动画，表达开心愉悦的情绪 | 播放 dance 动画 |
| Sleepy | yawn | 播放打哈欠动画，表达困倦想睡的情绪 | 播放 yawn 动画 |
| Touched | blush | 播放脸红动画，表达害羞感动的情绪 | 播放 blush 动画 |
| Angry | stomp | 播放跺脚动画，表达生气不满的情绪 | 播放 stomp 动画 |

## 工具执行流程

```
Agent 解析 LLM 响应中的 actions
        │
        ├── tool_call → ToolService.ExecuteToolAsync(toolName, parameters)
        │   ├── 基础工具 → 内置执行逻辑
        │   │   ├── timer → 启动/停止/暂停计时器
        │   │   ├── compliment → 生成夸奖语
        │   │   ├── pet → 返回摸头回应文本
        │   │   ├── weather → 查询天气
        │   │   ├── list_plugins → 列出外部工具
        │   │   └── reply → 提取回复文本
        │   │
        │   └── 心情特色工具 → 内置执行逻辑（只播放动画，不涉及情绪变化）
        │       ├── cry → 播放哭泣动画
        │       ├── dance → 播放跳舞动画
        │       ├── yawn → 播放打哈欠动画
        │       ├── blush → 播放脸红动画
        │       └── stomp → 播放跺脚动画
        │
        ├── mood_change → Agent.SetMood() 直接切换情绪
        │   └── 情绪变化通过 Agent.MoodChanged 事件通知 UI
        │
        ├── plugin_call → 路由到 DLLMOD 加载器
        │
        └── mcp_call → 路由到 MCP 服务管理
```

## 情绪变化流程

情绪变化不由 ToolService 触发（ToolService 作为基建不关心情绪），而是通过以下两种方式：

1. **LLM 主动切换**：LLM 在 actions 中返回 `mood_change` action，Agent 的 `ExecuteActionsAsync` 方法解析并调用 `SetMood()` 切换情绪。
2. **Agent 自动检测**：Agent 在 `ProcessUserInputAsync` 中根据用户消息内容（如"摸摸"、"夸"等关键词）和时间（深夜）自动调用 `UpdateMoodByEvent()` 切换情绪。

```
Agent 检测到情绪变化条件
        │
        ├── LLM 返回 mood_change action → Agent.ExecuteActionsAsync → SetMood()
        │
        └── Agent 自动检测（关键词/时间） → UpdateMoodByEvent() → SetMood()
                │
                ▼
        Agent.MoodChanged 事件 → UI 更新
```

## LLM 工具调用集成

Agent 在构建对话 prompt 时，按三层结构动态注入工具描述：

```csharp
// 第一层：基础工具（含 list_plugins）
var baseTools = _toolManager.GetToolDefinitions();

// 第二层：心情附加工具
var moodTools = _toolManager.GetMoodBasedTools(_agent.CurrentMood);

// 第三层：DLLMOD/MCP工具（通过 list_plugins 间接获取）
// LLM 需要先调用 list_plugins 获取列表
```

LLM 在回复中通过 actions 数组调用工具：

```json
{
  "reply": "好的，我帮你设置一个5分钟的倒计时～",
  "actions": [
    {"type": "tool_call", "name": "timer", "parameters": {"seconds": 300}}
  ]
}
```

## 外部工具注册

MCP 服务和 DLLMOD 插件可以通过 ToolManager 注册外部工具：

```csharp
// MCP 服务注册工具
_toolManager.RegisterExternalTool(
    new ToolDefinition
    {
        Name = "search_products",
        Description = "搜索电商商品",
        InputSchema = new Dictionary<string, object>
        {
            { "type", "object" },
            { "properties", new Dictionary<string, object>
                {
                    { "keyword", new Dictionary<string, object>
                        {
                            { "type", "string" },
                            { "description", "搜索关键词" }
                        }
                    }
                }
            },
            { "required", new[] { "keyword" } }
        }
    },
    async (parameters) => {
        // 调用 MCP 服务器
        return await _mcpClient.CallToolAsync("search_products", parameters);
    }
);
```

## DLLMOD 插件接口

DLLMOD 插件通过实现以下接口来注册工具：

```csharp
/// <summary>
/// DLLMOD 插件接口
/// </summary>
public interface IDllMod
{
    /// <summary>插件名称（唯一标识）</summary>
    string Name { get; }

    /// <summary>插件描述</summary>
    string Description { get; }

    /// <summary>执行插件功能</summary>
    /// <param name="parameters">传入参数（JSON格式）</param>
    /// <returns>执行结果（JSON格式）</returns>
    Task<string> ExecuteAsync(string parameters);
}

/// <summary>
/// DLLMOD 加载器接口
/// </summary>
public interface IDllModLoader
{
    /// <summary>从指定目录加载所有DLL插件</summary>
    /// <param name="modDirectory">插件目录路径</param>
    Task<List<IDllMod>> LoadModsAsync(string modDirectory);

    /// <summary>根据名称获取已加载的插件</summary>
    IDllMod GetMod(string name);

    /// <summary>执行指定名称的插件</summary>
    Task<string> ExecuteModAsync(string modName, string parameters = "");

    /// <summary>获取所有已加载的插件列表</summary>
    List<IDllMod> GetLoadedMods();

    /// <summary>重新加载所有插件（热更新）</summary>
    Task ReloadModsAsync();
}
```

## 依赖关系

- **依赖**: `LlmClient`（夸奖功能）、`IPromptFormatter`（Prompt格式化）
- **不依赖**: `IAgentMoodTracker`（情绪变化通过 LLM 的 mood_change action 走统一事件调度）
- **被依赖**: `Agent`（通过 Agent 统一调度工具调用）

## 单元测试要求

| 测试用例 | 预期结果 |
|---------|----------|
| 获取基础工具定义列表 | GetToolDefinitions 返回包含 timer/compliment/pet/weather 的列表 |
| 根据情绪获取附加工具 | GetMoodBasedTools(Sad) 返回包含 cry 的列表 |
| 情绪为 Neutral 时无附加工具 | GetMoodBasedTools(Neutral) 返回空列表 |
| 执行基础工具返回正确结果 | ExecuteToolAsync("timer", {"seconds": 60}) 返回成功 |
| 执行心情工具只播放动画 | ExecuteToolAsync("cry", "") 返回 animation 结果，不涉及情绪变化 |
| 注册外部工具后可用 | RegisterExternalTool 后 GetToolDefinitions 包含新工具 |
| 注销外部工具后移除 | UnregisterExternalTool 后工具从列表移除 |
| 执行不存在的工具返回错误 | ExecuteToolAsync("nonexistent", "") 返回 Success=false |
| 列出外部工具返回列表 | ListExternalToolsAsync 返回已注册的外部工具列表 |
