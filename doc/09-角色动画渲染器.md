# 角色动画渲染器 (CharacterRenderer)

## 模块概述

负责渲染桌宠的角色动画，支持 **精灵图（Sprite Sheet）**、**GIF 动画** 和 **单帧 PNG** 三种方式。根据当前情绪状态切换对应动画，提供生动的视觉交互体验。

### 动画类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| `sprite` | 精灵图 PNG 图集，按行列裁剪帧 | 主流动画方案，性能好 |
| `gif` | 直接播放 GIF 文件 | 兼容旧资源 |
| `png` | 单帧静态图片 | 简单表情/静态展示 |

## 数据模型

### SpriteSheetConfig

| 字段 | 类型 | 说明 |
|------|------|------|
| Type | string | 动画类型：`sprite` / `gif` / `png` |
| File | string | 资源文件名 |
| FrameWidth | int | 单帧宽度（像素） |
| FrameHeight | int | 单帧高度（像素） |
| TotalFrames | int | 总帧数 |
| Columns | int | 精灵图列数（sprite 类型） |
| Rows | int | 精灵图行数（sprite 类型） |
| Fps | int | 帧率（默认 10） |
| Loop | bool | 是否循环播放（默认 true） |
| NextAnimation | string? | 非循环动画播放完后切换到的动画名 |

### AnimationState

| 值 | 说明 |
|----|------|
| Stopped | 已停止 |
| Playing | 播放中 |
| Paused | 已暂停 |

## 核心接口

### ICharacterRenderer

```csharp
public interface ICharacterRenderer
{
    Task InitializeAsync(string resourcePath);
    void SetMotion(AgentMood mood);
    void PlayAnimation(string animationName);
    void SetOpacity(double opacity);
    void SetPosition(int x, int y);
    void Dispose();
}
```

### CharacterRenderer 额外公开属性

| 属性 | 类型 | 说明 |
|------|------|------|
| CurrentMood | AgentMood | 当前情绪 |
| CurrentAnimationName | string? | 当前动作名 |
| CurrentFrame | Image? | 当前帧图像（供 UI 层绑定） |
| IsInitialized | bool | 是否已初始化 |
| FrameUpdated | event Action? | 帧改变事件（供 UI 层订阅刷新 PictureBox） |

## 实现要点

### 资源目录结构

```
Resources/Images/
├── {情绪名}/              # 如 neutral, happy, sad...
│   ├── {动作名}/          # 如 默认, 眨眼, 委屈...
│   │   ├── idle.json      # 动画配置（帧率、循环等）
│   │   └── idle.png       # 精灵图 PNG
│   └── ...
└── ...
```

### 情绪→动作映射

- `InitializeAsync` 时扫描资源目录，建立 `Dictionary<AgentMood, List<string>>` 映射
- 目录名（如 `neutral`）通过 `ParseMood()` 解析为 `AgentMood` 枚举
- `SetMotion(mood)` 默认选择该情绪下的第一个动作播放
- 若目标情绪无资源，自动回退到 `Neutral`

### 动画播放

- `CharacterRenderer` 作为状态机，指挥 `SpriteRenderer` 渲染
- `SpriteRenderer` 支持三种加载方式：`LoadFromJson()` / `LoadFromConfig()` / 直接加载 PNG
- 使用 `System.Timers.Timer` 按帧率驱动帧切换（最小间隔 16ms ≈ 60fps）
- 非循环动画播放完毕后触发 `AnimationCompleted` 事件，自动切换到 `NextAnimation`
- 已加载的 `SpriteRenderer` 实例缓存到 `_rendererCache`，避免重复加载

### 帧更新通知

- `SpriteRenderer.FrameChanged` → `CharacterRenderer.OnFrameChanged` → `CharacterRenderer.FrameUpdated`
- UI 层订阅 `FrameUpdated` 事件刷新 PictureBox

### 透明度与位置

- `SetOpacity` 使用 `Math.Clamp` 限制在 0.0~1.0 范围
- `SetPosition` 记录坐标，由 UI 层实际应用

## 依赖关系

- **依赖**: `System.Drawing`（WinForms 内置）
- **被依赖**: `MainWindow`（UI 层承载 PictureBox 控件）、`Agent`（情绪变化驱动动画切换）

## 单元测试

### 测试要点

| 测试用例 | 预期结果 |
|----------|----------|
| 初始化后状态就绪 | `InitializeAsync` 完成后 `IsInitialized` 为 true |
| 设置情绪切换动画 | `SetMotion(Neutral)` 后 `CurrentMood` 为 Neutral，`CurrentFrame` 不为 null |
| 无资源情绪回退 | 无资源的情绪 `SetMotion` 后 `CurrentMood` 保持目标值，不抛异常 |
| 播放不存在的动画 | `PlayAnimation("nonexistent")` 静默忽略，不抛异常 |
| 设置透明度 | `SetOpacity(0.5)` 后 `GetOpacity()` 返回 0.5；超范围值被 clamp |
| 设置位置 | `SetPosition(100, 200)` 后 `GetPositionX/Y` 返回对应值 |
| 帧更新事件 | `FrameUpdated` 事件订阅后不抛异常 |
| 释放资源 | `Dispose` 后 `IsInitialized` 为 false |
| 空路径初始化 | 不存在的路径自动创建目录，初始化成功 |
