# 角色动画渲染器 (CharacterRenderer)

## 模块概述

负责渲染 AI 女友的角色动画，支持 **GIF 动画** 和 **PNG 图集** 两种方式，根据当前情绪状态切换对应动画，提供生动的视觉交互体验。

### GIF 动画方案

- 使用 `System.Drawing.Image` 加载 GIF 文件，通过 `ImageAnimator` 控制动画播放
- 每帧更新通过 `Timer` 驱动，刷新 PictureBox 显示

### PNG 图集方案

- 将多帧 PNG 图片按顺序命名（如 `happy_01.png`, `happy_02.png`）
- 通过 `Timer` 按帧率切换显示的图片
- 支持每套动画独立配置帧率和循环模式

## 接口定义

### 核心接口

```csharp
/// <summary>
/// 角色动画渲染器接口
/// </summary>
public interface ICharacterRenderer
{
    /// <summary>初始化渲染器</summary>
    /// <param name="resourcePath">角色资源文件夹路径</param>
    Task InitializeAsync(string resourcePath);

    /// <summary>根据情绪切换动画</summary>
    /// <param name="mood">目标情绪</param>
    void SetMotion(AgentMood mood);

    /// <summary>播放指定动画（如拥抱、摸头等特殊交互）</summary>
    /// <param name="animationName">动画名称</param>
    void PlayAnimation(string animationName);

    /// <summary>设置角色透明度</summary>
    /// <param name="opacity">透明度值 0.0-1.0</param>
    void SetOpacity(double opacity);

    /// <summary>设置角色在窗口中的位置</summary>
    /// <param name="x">X坐标</param>
    /// <param name="y">Y坐标</param>
    void SetPosition(int x, int y);

    /// <summary>释放渲染资源</summary>
    void Dispose();
}
```

## 资源目录结构

角色资源按文件夹组织，每个角色一个独立目录：

```txt
Resources/Images/
├── default/                    # 默认角色
│   ├── config.json             # 动画配置（帧率、循环等）
│   ├── idle.gif                # 待机动画（GIF方案）
│   ├── happy.gif               # 开心动画
│   ├── sad.gif                 # 委屈动画
│   ├── sleepy.gif              # 困倦动画
│   ├── touched.gif             # 被摸头动画
│   ├── neutral.gif             # 平静动画
│   ├── teasing.gif             # 调皮动画
│   ├── angry.gif               # 生气动画
│   ├── surprised.gif           # 惊讶动画
│   ├── hug.gif                 # 拥抱动画
│   ├── pet_head.gif            # 摸头动画
│   └── wave.gif                # 挥手动画
│
└── custom/                     # 自定义角色（用户可添加）
    └── ...
```

### PNG 图集方案目录结构

```txt
Resources/Images/
└── default_png/                # PNG图集方案示例
    ├── config.json             # 动画配置
    ├── idle/                   # 待机动画帧
    │   ├── 01.png
    │   ├── 02.png
    │   └── ...
    ├── happy/
    │   ├── 01.png
    │   ├── 02.png
    │   └── ...
    └── ...
```

### config.json 配置格式

```json
{
  "format": "gif",
  "animations": {
    "idle":       { "file": "idle.gif",       "loop": true },
    "happy":      { "file": "happy.gif",      "loop": true },
    "sad":        { "file": "sad.gif",        "loop": true },
    "sleepy":     { "file": "sleepy.gif",     "loop": true },
    "touched":    { "file": "touched.gif",    "loop": true },
    "neutral":    { "file": "neutral.gif",    "loop": true },
    "teasing":    { "file": "teasing.gif",    "loop": true },
    "angry":      { "file": "angry.gif",      "loop": true },
    "surprised":  { "file": "surprised.gif",  "loop": true },
    "hug":        { "file": "hug.gif",        "loop": false, "next": "happy" },
    "pet_head":   { "file": "pet_head.gif",   "loop": false, "next": "touched" },
    "wave":       { "file": "wave.gif",       "loop": false, "next": "idle" }
  }
}
```

> `loop: false` 的动画播放完毕后自动切换到 `next` 指定的动画。

## 情绪-动画映射表

| 情绪 | 动画文件 | 说明 |
| ------ | ---------- | ------ |
| Happy | happy.gif | 开心时的动画 |
| Sad | sad.gif | 委屈时的动画 |
| Sleepy | sleepy.gif | 困倦时的动画 |
| Touched | touched.gif | 被摸头后的反应 |
| Neutral | neutral.gif | 默认状态 |
| Teasing | teasing.gif | 调皮时的动画 |
| Angry | angry.gif | 生气时的动画 |
| Surprised | surprised.gif | 惊讶时的动画 |

## 特殊动画

| 动画名称 | 触发场景 | 描述 |
| ---------- | ---------- | ------ |
| hug | 双击头像 / 拥抱功能 | 张开双臂的拥抱动作 |
| pet_head | 点击"摸摸她" | 头上出现抚摸的手 |
| wave | 用户打开工具菜单 | 挥手打招呼 |

## 事件流

`AgentMoodTracker.MoodChanged` 事件触发后，调用 `SetMotion(mood)` 切换动画，渲染器加载对应情绪动画文件并播放。

## 单元测试

### 测试要点

| 测试用例 | 预期结果 |
| ---------- | ---------- |
| 初始化后状态就绪 | InitializeAsync 完成后可正常调用其他方法 |
| 设置情绪切换动画 | SetMotion(Happy) 切换到对应动画 |
| 播放动画不抛异常 | PlayAnimation("hug") 正常执行 |
| 设置透明度生效 | SetOpacity(0.5) 后透明度改变 |
| 设置位置生效 | SetPosition(100, 200) 后位置改变 |
| 释放资源后状态清理 | Dispose 后资源释放 |
| 无效动画名称不抛异常 | PlayAnimation("nonexistent") 静默忽略或回退到 idle |

### 测试方法

```csharp
[Fact]
public async Task Initialize_ShouldCompleteSuccessfully()
{
    var renderer = new CharacterRenderer();
    await renderer.InitializeAsync("./Resources/Images/default/");
    // 初始化成功，无异常抛出
}

[Fact]
public void SetMotion_ShouldNotThrow()
{
    var renderer = new CharacterRenderer();
    renderer.SetMotion(AgentMood.Happy);
    // 动画切换正常，无异常
}

[Fact]
public void PlayAnimation_ShouldNotThrow()
{
    var renderer = new CharacterRenderer();
    renderer.PlayAnimation("hug");
    // 动画播放正常，无异常
}

[Fact]
public void SetOpacity_ShouldChangeOpacity()
{
    var renderer = new CharacterRenderer();
    renderer.SetOpacity(0.5);
    // 透明度设置正常
}
```

## 依赖关系

- **被依赖**: `Form1`（UI层承载 PictureBox 控件）、`AgentMoodTracker`（情绪变化驱动动画切换）
