## 协作须知

请先阅读 `doc/00 - 写给viber的话.md`，了解本项目的基本协作规范：

- **Git 提交格式**：`影响程度词：一句话描述`（如 `功能改动：添加天气查询模块`）

**分层窗口鼠标事件关键**：

`AllowsTransparency="True"` 的 WPF 窗口，`Background="Transparent"` 会导致所有像素区域鼠标穿透。解决：`Background="#01000000"`（alpha=1，肉眼不可见但对分层窗口来说是不透明像素）。

### 已解决的技术问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| WebView2 分层窗口鼠标完全穿透 | `AllowsTransparency="True"` + `Background="Transparent"` 使所有透明像素区域可穿透 | `Background="#01000000"`（alpha=1，肉眼不可见但对分层窗口不透明） |
| WebView2 CSS `-webkit-app-region: drag` 无效 | WebView2 默认不启用 draggable regions | `CoreWebView2EnvironmentOptions` 添加 `--enable-features=msWebView2EnableDraggableRegions` |
| WebView2 中 OrbitControls 拖动与窗口拖动冲突 | Three.js OrbitControls 拦截鼠标事件 | `enableRotate/enablePan/enableZoom = false`，鼠标事件穿透到 CSS drag 层 |

## 九、技术债 & 潜在问题

1. **空 catch 模式**：多处 `try { } catch { }`（EventDispatcher.Publish、BuiltinTaskHandler 等），可能掩盖真实问题

3. **XAML 硬编码**：`ChatWindow.xaml` 中 `Title="小琪"` 和 `Text="小琪"` 是设计时默认值，可改为数据绑定
