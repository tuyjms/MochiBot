# 工作安排

## 情绪→动画联动方案

### 设计思路

LLM 根据对话内容切换心情，心情再由系统自动切换动画。

### 当前实现

#### 心情切换入口

| 入口 | 方式 | 说明 |
|------|------|------|
| LLM 输出 `mood_change` action | `ActionExecutor` → `SetMood()` | LLM 在 actions 中指定心情 |
| 系统自动事件 | `UpdateMoodByEvent()` | 根据事件类型（LateNight/Pet/Compliment 等）映射心情 |
| 用户消息关键词检测 | `DetectAndTriggerMoodEvent()` | 检测"摸摸""夸"等关键词触发心情 |
| UI 交互事件 | 事件订阅 → `UpdateMoodByEvent("Pet")` | 如"摸摸她"按钮 |

#### 情绪→动画联动流程

```
Agent 心情变化
  → SetMood() 发布 EventCategory.MoodChange 事件到事件调度器
    → 事件调度器通知订阅者
      → 角色动画器接收 MoodChange 事件，切换对应动画
```

#### 心情附加工具

ToolService 为每种心情注册了一个动画工具，LLM 可主动调用：

| 心情 | 工具名 | 动画 |
|------|--------|------|
| Sad | `cry` | 哭泣动画 |
| Happy | `dance` | 跳舞动画 |
| Sleepy | `yawn` | 打哈欠动画 |
| Touched | `blush` | 脸红动画 |
| Angry | `stomp` | 跺脚动画 |

### 优势

- **省上下文**：LLM 只需输出 `mood_change` action，无需额外调用工具
- **反应快**：省去工具调用链路，心情切换后动画即时响应
- **随机动画**：同一心情下可配置多套动作，系统随机选择，增加生动感
