# 中期记忆 (MidTermMemory)

## 模块概述

介于短期记忆和长期记忆之间，负责记录具有一定重要性的对话事件。采用 JSON 文件存储，每条记录包含时间戳、事件描述和重要度评分。中期记忆是短期记忆向长期记忆过渡的"缓冲区"。

## 数据模型

```csharp
public class MidTermMemoryEntry
{
    public string Id { get; set; } = Guid.NewGuid().ToString();
    public DateTime Timestamp { get; set; }
    public string Description { get; set; } = string.Empty;
    public int Importance { get; set; }          // 0-100
    public string Source { get; set; } = string.Empty;  // LLM / Overflow / KeywordScan
    public List<string>? RelatedMessageIds { get; set; }
    public bool PromotedToLongTerm { get; set; } = false;
}
```

## 核心接口

```csharp
public interface IMidTermMemory
{
    Task AddEntryAsync(MidTermMemoryEntry entry);
    Task AddEntriesAsync(IEnumerable<MidTermMemoryEntry> entries);
    Task<List<MidTermMemoryEntry>> GetAllEntriesAsync();
    Task<List<MidTermMemoryEntry>> GetEntriesByImportanceAsync(int minImportance);
    Task<List<MidTermMemoryEntry>> GetEntriesByTimeRangeAsync(DateTime start, DateTime end);
    Task<List<MidTermMemoryEntry>> GetRecentEntriesAsync(int count = 20);
    Task MarkAsPromotedAsync(string entryId);
    Task DeleteEntryAsync(string entryId);
    Task<int> GetCountAsync();
    Task ClearAsync();
}
```

## 录入机制

### 机制A：LLM主动调用

对话LLM在每次回复时，判断当前对话内容是否有值得记录的信息，主动调用 `AddEntryAsync()`。

**触发条件**：LLM在回复中检测到以下情况时主动录入：

- 用户提到个人偏好（"我喜欢吃辣"）
- 用户提到重要事件（"我下周要面试"）
- 用户表达强烈情绪（"我今天升职了！"）
- 用户提出长期需求（"帮我每天提醒我吃药"）

**实现方式**：在 LLM 的 system prompt 中加入指令，让 LLM 在回复时附带一个特殊的结构化标记，由后端解析后录入中期记忆。

```txt
[记忆标记]
{
  "type": "midterm_memory",
  "description": "用户喜欢吃辣，特别是四川火锅",
  "importance": 70
}
[/记忆标记]
```

### 机制B：爆上下文时概率触发

当短期记忆触发 Overflow 处理时，按概率抽取部分记忆录入中期。

**触发条件**：短期记忆 `AddMessage()` 检测到 count > Capacity

**处理流程**：

1. 从即将被淘汰的旧记录中，按概率抽取 20%-50% 的记录
2. 对每条抽取的记录：提取关键信息，由LLM评估重要度(0-100)，录入中期记忆

**概率公式**：`P = min(0.5, 0.2 + 重要度因子 * 0.3)`

- 普通对话：20% 概率
- 包含关键词（喜欢/讨厌/想要/记得等）：30%-50% 概率

### 机制C：定期关键词扫描

定时任务从短期记忆中，通过出现频率最高的词查找相关聊天记录并录入。

**触发条件**：定时任务（默认每30分钟执行一次）

**处理流程**：

1. 扫描短期记忆中的所有消息，统计词频，找出TOP 10关键词
2. 用这些关键词反向查找相关的完整对话段落
3. 对找到的对话段落：去重、LLM评估重要度、录入中期记忆

**关键词过滤**：排除停用词（的、了、是、在、有、我、你等）

## 配置参数

| 参数 | 默认值 | 说明 |
| MaxEntries | 500 | 中期记忆最大条目数 |
| ImportanceThreshold | 30 | 最低录入重要度（低于此值不录入） |
| OverflowSampleRate | 0.3 | 爆上下文时的采样率 0.2-0.5 |
| KeywordScanInterval | 30 | 关键词扫描间隔（分钟） |
| TopKeywordsCount | 10 | 每次扫描提取的关键词数量 |
| StoragePath | Resources/Data/midterm_memory.json | 存储路径 |

## 事件流

中期记忆有三个录入入口：LLM主动调用、短期记忆溢出触发、定时关键词扫描。三个入口最终都调用 `AddEntryAsync()` 录入。录入时检查重要度是否超过阈值(>80)，如果超过则同步触发长期记忆录入。最后持久化到 midterm_memory.json。

## 单元测试

### 测试要点

| 测试用例 | 预期结果 |
| ---------- | ---------- |
| 添加单条记录 | AddEntryAsync 后 GetCountAsync == 1 |
| 批量添加记录 | AddEntriesAsync 后 GetCountAsync 等于添加数量 |
| 按重要度筛选 | GetEntriesByImportanceAsync(70) 只返回重要度 >= 70 的记录 |
| 按时间范围筛选 | GetEntriesByTimeRangeAsync 只返回指定范围内的记录 |
| 标记为已提升 | MarkAsPromotedAsync 后 PromotedToLongTerm 为 true |
| 删除记录 | DeleteEntryAsync 后 GetCountAsync 减少 |
| 清空所有记录 | ClearAsync 后 GetCountAsync == 0 |
| 获取最近 N 条 | GetRecentEntriesAsync(5) 返回 5 条 |

### 测试方法

```csharp
[Fact]
public async Task AddEntry_ShouldIncreaseCount()
{
    var memory = new MidTermMemory();
    await memory.AddEntryAsync(new MidTermMemoryEntry
    {
        Description = "测试事件",
        Importance = 50
    });
    Assert.Equal(1, await memory.GetCountAsync());
}

[Fact]
public async Task GetEntriesByImportance_ShouldFilter()
{
    var memory = new MidTermMemory();
    await memory.AddEntriesAsync(new[]
    {
        new MidTermMemoryEntry { Description = "低", Importance = 30 },
        new MidTermMemoryEntry { Description = "高", Importance = 80 }
    });
    var high = await memory.GetEntriesByImportanceAsync(70);
    Assert.Single(high);
    Assert.Equal("高", high[0].Description);
}

[Fact]
public async Task MarkAsPromoted_ShouldUpdateFlag()
{
    var memory = new MidTermMemory();
    var entry = new MidTermMemoryEntry { Description = "test", Importance = 50 };
    await memory.AddEntryAsync(entry);
    await memory.MarkAsPromotedAsync(entry.Id);
    var entries = await memory.GetAllEntriesAsync();
    Assert.True(entries.First(e => e.Id == entry.Id).PromotedToLongTerm);
}

[Fact]
public async Task Clear_ShouldResetCount()
{
    var memory = new MidTermMemory();
    await memory.AddEntryAsync(new MidTermMemoryEntry { Description = "test", Importance = 50 });
    await memory.ClearAsync();
    Assert.Equal(0, await memory.GetCountAsync());
}
```

## 依赖关系

- **依赖**: `DatabaseService`（持久化）、`LlmClient`（LLM评估重要度）、`ShortTermMemory`（读取短期记忆）
- **被依赖**: `LongTermMemory`（从中期提升到长期）
