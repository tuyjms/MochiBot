# 数据库业务层 (DatabaseService)

## 模块概述

负责所有数据的持久化存储和读取，包括用户配置、聊天记录、情绪日志等。采用 **SQLite** 数据库存储（通过 `Microsoft.Data.Sqlite` 实现）。

## 接口定义

### 数据模型

```csharp
/// <summary>
/// 用户配置模型
/// </summary>
public class UserConfig
{
    /// <summary>AI女友的名字</summary>
    public string Name { get; set; } = "小可爱";

    /// <summary>性格：温柔 / 毒舌 / 活泼</summary>
    public string Personality { get; set; } = "温柔";

    /// <summary>窗口透明度 0.0-1.0</summary>
    public double Opacity { get; set; } = 1.0;

    /// <summary>碎碎念功能开关</summary>
    public bool MurmurEnabled { get; set; } = true;

    /// <summary>碎碎念间隔（分钟）</summary>
    public int MurmurInterval { get; set; } = 30;

    /// <summary>窗口位置 X</summary>
    public int WindowPosX { get; set; } = 100;

    /// <summary>窗口位置 Y</summary>
    public int WindowPosY { get; set; } = 100;
}

/// <summary>
/// 情绪日志条目
/// </summary>
public class MoodLogEntry
{
    public DateTime Timestamp { get; set; }
    public AgentMood Mood { get; set; }
    public string Trigger { get; set; }  // 触发原因
}
```

### 核心接口

```csharp
/// <summary>
/// 数据库服务接口
/// </summary>
public interface IDatabaseService
{
    // ========== 用户配置 ==========

    /// <summary>加载用户配置</summary>
    Task<UserConfig> LoadConfigAsync();

    /// <summary>保存用户配置</summary>
    Task SaveConfigAsync(UserConfig config);


    // ========== 聊天记录 ==========

    /// <summary>保存聊天记录到历史</summary>
    /// <param name="messages">要保存的消息列表</param>
    Task SaveChatHistoryAsync(List<ChatMessage> messages);

    /// <summary>加载历史聊天记录</summary>
    /// <param name="limit">加载条数，默认50条</param>
    Task<List<ChatMessage>> LoadChatHistoryAsync(int limit = 50);


    // ========== 情绪日志 ==========

    /// <summary>记录情绪变化</summary>
    /// <param name="mood">变化后的情绪</param>
    /// <param name="trigger">触发原因</param>
    Task LogMoodChangeAsync(AgentMood mood, string trigger);

    /// <summary>查询指定时间范围内的情绪日志</summary>
    Task<List<MoodLogEntry>> GetMoodLogAsync(DateTime start, DateTime end);
}
```

## 存储方案

### 数据库表结构

```sql
-- 用户配置表（单行表）
CREATE TABLE IF NOT EXISTS UserConfig (
    Id          INTEGER PRIMARY KEY,
    Name        TEXT    NOT NULL DEFAULT '小可爱',
    Personality TEXT    NOT NULL DEFAULT '温柔',
    Opacity     REAL    NOT NULL DEFAULT 1.0,
    MurmurEnabled INTEGER NOT NULL DEFAULT 1,
    MurmurInterval INTEGER NOT NULL DEFAULT 30,
    WindowPosX  INTEGER NOT NULL DEFAULT 100,
    WindowPosY  INTEGER NOT NULL DEFAULT 100
);

-- 聊天记录表
CREATE TABLE IF NOT EXISTS ChatMessages (
    Id        INTEGER PRIMARY KEY AUTOINCREMENT,
    Role      TEXT    NOT NULL,
    Content   TEXT    NOT NULL,
    Timestamp TEXT    NOT NULL
);

-- 情绪日志表
CREATE TABLE IF NOT EXISTS MoodLog (
    Id        INTEGER PRIMARY KEY AUTOINCREMENT,
    Timestamp TEXT    NOT NULL,
    Mood      INTEGER NOT NULL,
    Trigger   TEXT    NOT NULL
);
```

## 事件流

其他服务调用 DatabaseService 的接口，DatabaseService 读写 `Resources/Data/mochibot.db` SQLite 数据库文件。

### 测试要点

| 测试用例 | 预期结果 |
|----------|----------|
| 保存配置后加载配置一致 | SaveConfigAsync 后 LoadConfigAsync 返回相同内容 |
| 保存聊天记录后加载 | SaveChatHistoryAsync 后 LoadChatHistoryAsync 返回相同记录 |
| 记录情绪日志后查询 | LogMoodChangeAsync 后 GetMoodLogAsync 包含该记录 |
| 加载聊天记录限制条数 | LoadChatHistoryAsync(limit) 返回不超过 limit 条 |
| 查询情绪日志时间范围 | GetMoodLogAsync(start, end) 只返回指定范围内的记录 |
| 文件不存在时返回默认值 | 首次 LoadConfigAsync 返回默认 UserConfig |

### 测试方法

```csharp
using catgirlwindow.Models;
using catgirlwindow.Services;

namespace catgirlwindow.Tests.Services;

public class DatabaseServiceTests : IDisposable
{
    private readonly string _testDbPath;
    private readonly string _connectionString;
    private readonly DatabaseService _db;

    public DatabaseServiceTests()
    {
        // 每个测试使用独立的 SQLite 临时数据库
        _testDbPath = Path.Combine(Path.GetTempPath(), $"mochibot_test_{Guid.NewGuid()}.db");
        _connectionString = $"Data Source={_testDbPath}";
        _db = new DatabaseService(_connectionString);
    }

    public void Dispose()
    {
        // 清理测试数据库文件
        try { if (File.Exists(_testDbPath)) File.Delete(_testDbPath); }
        catch { /* 忽略清理时的异常 */ }
    }

    [Fact]
    public async Task SaveAndLoadConfig_ShouldBeConsistent()
    {
        var config = new UserConfig { Name = "测试女友", Personality = "活泼" };
        await _db.SaveConfigAsync(config);
        var loaded = await _db.LoadConfigAsync();
        Assert.Equal(config.Name, loaded.Name);
        Assert.Equal(config.Personality, loaded.Personality);
    }

    [Fact]
    public async Task LogMood_ShouldBeRetrievable()
    {
        await _db.LogMoodChangeAsync(AgentMood.Happy, "UserCompliment");
        var logs = await _db.GetMoodLogAsync(DateTime.MinValue, DateTime.MaxValue);
        Assert.Contains(logs, l => l.Mood == AgentMood.Happy && l.Trigger == "UserCompliment");
    }

    [Fact]
    public async Task LoadChatHistory_ShouldRespectLimit()
    {
        var messages = new List<ChatMessage>();
        for (int i = 0; i < 10; i++)
            messages.Add(new ChatMessage { Role = "user", Content = $"msg{i}" });

        await _db.SaveChatHistoryAsync(messages);
        var loaded = await _db.LoadChatHistoryAsync(limit: 3);
        Assert.Equal(3, loaded.Count);
    }
}
```
