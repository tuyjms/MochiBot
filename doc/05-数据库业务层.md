# 数据库业务层 (DatabaseService)

## 模块概述

负责所有数据的持久化存储和读取，包括用户配置、聊天记录、情绪日志等。采用 **SQLite** 数据库存储（通过 `Microsoft.Data.Sqlite` 实现）。

### 数据库文件

```txt
Resources/
└── Data/
    └── mochibot.db          # SQLite 数据库文件
```

## 事件流

其他服务调用 DatabaseService 的接口，DatabaseService 读写 `Resources/Data/mochibot.db` SQLite 数据库文件。

### 测试要点

| 测试用例 | 预期结果 |
| ---------- | ---------- |
| 保存配置后加载配置一致 | SaveConfigAsync 后 LoadConfigAsync 返回相同内容 |
| 保存聊天记录后加载 | SaveChatHistoryAsync 后 LoadChatHistoryAsync 返回相同记录 |
| 增量追加单条消息 | SaveSingleMessageAsync 追加后不丢失旧数据，顺序正确 |
| 多条增量追加保序 | 多次 SaveSingleMessageAsync 后 LoadChatHistoryAsync 返回正确顺序 |
| 记录情绪日志后查询 | LogMoodChangeAsync 后 GetMoodLogAsync 包含该记录 |
| 加载聊天记录限制条数 | LoadChatHistoryAsync(limit) 返回不超过 limit 条 |
| 查询情绪日志时间范围 | GetMoodLogAsync(start, end) 只返回指定范围内的记录 |
| 文件不存在时返回默认值 | 首次 LoadConfigAsync 返回默认 UserConfig |

## 聊天记录持久化

### 数据流

```
用户输入 → Agent.ProcessWithLlmAsync
  → ShortTermMemory.AddMessage(User)           ← 内存环形缓冲
  → ChatHistoryRepository.SaveSingleMessageAsync(User)   ← SQLite 持久化
  → LLM 调用
  → ShortTermMemory.AddMessage(Assistant)
  → ChatHistoryRepository.SaveSingleMessageAsync(Assistant) ← SQLite 持久化

启动恢复：
  MemoryCoordinator.WarmUpFromDatabaseAsync → 从 SQLite 加载到 ShortTermMemory（LLM 上下文恢复）
  ChatWindow.LoadHistoryAsync → 从 SQLite 加载到 UI 消息列表（界面恢复）
```

### ChatHistoryRepository 方法

| 方法 | 说明 |
|------|------|
| `SaveSingleMessageAsync(ChatMessage)` | 增量追加单条消息（INSERT，不清空表） |
| `SaveChatHistoryAsync(List<ChatMessage>)` | 批量保存（DELETE 全表 + INSERT，用于测试/全量同步） |
| `LoadChatHistoryAsync(int limit)` | 加载最近 N 条消息（按时间正序返回） |

## 依赖关系

- **依赖**: `Microsoft.Data.Sqlite`（NuGet 包）
- **被依赖**: `MainAgent`（实时持久化聊天记录）、`MemoryCoordinator`（启动预热 ShortTermMemory）、`ChatWindow`（加载历史 UI）、`MoodManager`（记录情绪日志）
