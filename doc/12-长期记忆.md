# 长期记忆 (LongTermMemory)

## 模块概述

负责存储最重要的、需要长期保留的记忆信息。采用关系型数据库（SQLite）存储，每条记录包含关键词索引、事件描述、时间戳和重要度评分。长期记忆是 AI 女友的"永久记忆"，用于在对话中 recall 用户的重要信息。

## 数据模型

```csharp
public class LongTermMemoryEntry
{
    public string Id { get; set; } = Guid.NewGuid().ToString();
    public string Keyword1 { get; set; } = string.Empty;  // 主词，通常是主语
    public string Keyword2 { get; set; } = string.Empty;  // 通常是谓语/动作
    public string Keyword3 { get; set; } = string.Empty;  // 通常是宾语/对象
    public string Description { get; set; } = string.Empty;
    public DateTime EventTimestamp { get; set; }
    public int Importance { get; set; }                    // 0-100
    public DateTime CreatedAt { get; set; } = DateTime.Now;
    public DateTime LastAccessedAt { get; set; } = DateTime.Now;
    public int AccessCount { get; set; } = 0;
    public string Source { get; set; } = string.Empty;     // MidTermPromotion / ThresholdTrigger
}
```

## 关键词提取规则

### 优先规则：主谓宾提取

当事件描述是一个完整的句子时，优先提取主谓宾作为三个关键词。

例句："用户喜欢吃四川火锅" → 关键词1:"用户" 关键词2:"喜欢吃" 关键词3:"四川火锅"
例句："用户下周要去北京面试" → 关键词1:"用户" 关键词2:"去" 关键词3:"北京面试"

### 后备规则：无主谓宾时用3个关键词

当事件描述不是完整句子时，提取3个最重要的关键词。

描述："对猫毛过敏" → 关键词1:"猫" 关键词2:"过敏" 关键词3:"宠物"
描述："害怕打雷" → 关键词1:"害怕" 关键词2:"打雷" 关键词3:"天气"

### 关键词提取实现

由 LLM 负责从事件描述中提取关键词，调用专门的 prompt：

```txt
请从以下事件描述中提取3个关键词：
1. 优先提取主谓宾结构
2. 如果没有主谓宾，提取3个最重要的关键词
3. 关键词应为名词或动词原形
4. 返回JSON格式

事件描述：{description}

返回格式：
{"keyword1": "...", "keyword2": "...", "keyword3": "..."}
```

## 核心接口

```csharp
public interface ILongTermMemory
{
    Task AddEntryAsync(LongTermMemoryEntry entry);
    Task AddEntriesAsync(IEnumerable<LongTermMemoryEntry> entries);
    Task<List<LongTermMemoryEntry>> SearchByKeywordsAsync(List<string> keywords, int topN = 5);
    Task<List<LongTermMemoryEntry>> GetEntriesByImportanceAsync(int minImportance);
    Task<List<LongTermMemoryEntry>> GetEntriesByTimeRangeAsync(DateTime start, DateTime end);
    Task<List<LongTermMemoryEntry>> GetRecentEntriesAsync(int count = 20);
    Task<LongTermMemoryEntry?> GetEntryByIdAsync(string id);
    Task UpdateAccessInfoAsync(string entryId);
    Task DeleteEntryAsync(string entryId);
    Task<int> GetCountAsync();
    Task ClearAsync();
}
```

## 录入机制

### 机制A：定期从中期数据库查找重要度高的记录

**触发条件**：定时任务（默认每60分钟执行一次）

**处理流程**：

1. 查询中期记忆中 PromotedToLongTerm == false 且 Importance >= 60 的记录
2. 对每条记录：调用LLM提取关键词(主谓宾)，构建 LongTermMemoryEntry
3. 录入长期记忆（SQLite），标记中期记忆为已提升

### 机制B：中期记忆录入时重要度超过阈值

**触发条件**：`IMidTermMemory.AddEntryAsync()` 被调用时，检查 `entry.Importance > 80`

**处理流程**：

1. 如果重要度 > 80，同步调用LLM提取关键词
2. 构建 LongTermMemoryEntry 录入 SQLite
3. 标记中期记忆为已提升
4. 如果重要度 <= 80，仅录入中期记忆，等待定期提升

## 数据库设计（SQLite）

### 表结构

```sql
CREATE TABLE IF NOT EXISTS long_term_memory (
    id              TEXT PRIMARY KEY,
    keyword1        TEXT NOT NULL,
    keyword2        TEXT NOT NULL,
    keyword3        TEXT NOT NULL,
    description     TEXT NOT NULL,
    event_timestamp TEXT NOT NULL,
    importance      INTEGER NOT NULL DEFAULT 0,
    created_at      TEXT NOT NULL,
    last_accessed_at TEXT NOT NULL,
    access_count    INTEGER NOT NULL DEFAULT 0,
    source          TEXT NOT NULL DEFAULT ''
);

CREATE INDEX IF NOT EXISTS idx_keyword1 ON long_term_memory(keyword1);
CREATE INDEX IF NOT EXISTS idx_keyword2 ON long_term_memory(keyword2);
CREATE INDEX IF NOT EXISTS idx_keyword3 ON long_term_memory(keyword3);
CREATE INDEX IF NOT EXISTS idx_importance ON long_term_memory(importance DESC);
CREATE INDEX IF NOT EXISTS idx_event_timestamp ON long_term_memory(event_timestamp DESC);
```

### 关键词搜索 SQL

```sql
SELECT DISTINCT *
FROM long_term_memory
WHERE (keyword1 IN ({keywords}) OR keyword2 IN ({keywords}) OR keyword3 IN ({keywords}))
ORDER BY importance DESC, last_accessed_at DESC
LIMIT {topN};
```

## 配置参数

| 参数 | 默认值 | 说明 |
| PromotionInterval | 60 | 定期提升扫描间隔（分钟） |
| PromotionThreshold | 60 | 定期提升的最低重要度 |
| ImmediateThreshold | 80 | 即时触发长期记忆的重要度阈值 |
| MaxEntries | 10000 | 长期记忆最大条目数 |
| DbPath | Resources/Data/long_term_memory.db | SQLite数据库路径 |
| SearchTopN | 5 | 关键词搜索返回前N条结果 |

## 事件流

长期记忆有两个录入入口：定期从中期扫描重要记录（机制A），以及中期录入时重要度超过阈值即时触发（机制B）。两个入口都先调用LLM提取关键词（函数模式），然后写入 SQLite 数据库，最后标记中期记忆为已提升。在对话时，PromptFormatter 通过 SearchByKeywordsAsync() 检索相关长期记忆注入上下文。

## 单元测试

### 测试要点

| 测试用例 | 预期结果 |
|----------|----------|
| 添加单条记录 | AddEntryAsync 后 GetCountAsync == 1 |
| 按关键词搜索 | SearchByKeywordsAsync(["猫"]) 返回包含"猫"的记录 |
| 按重要度筛选 | GetEntriesByImportanceAsync(70) 只返回重要度 >= 70 的记录 |
| 按时间范围筛选 | GetEntriesByTimeRangeAsync 只返回指定范围内的记录 |
| 更新访问信息 | UpdateAccessInfoAsync 后 LastAccessedAt 更新 |
| 删除记录 | DeleteEntryAsync 后 GetCountAsync 减少 |
| 清空所有记录 | ClearAsync 后 GetCountAsync == 0 |
| 获取最近 N 条 | GetRecentEntriesAsync(5) 返回 5 条 |

### 测试方法

```csharp
[Fact]
public async Task AddEntry_ShouldIncreaseCount()
{
    var memory = new LongTermMemory();
    await memory.AddEntryAsync(new LongTermMemoryEntry
    {
        Keyword1 = "用户",
        Keyword2 = "喜欢",
        Keyword3 = "猫",
        Description = "用户喜欢猫",
        Importance = 80
    });
    Assert.Equal(1, await memory.GetCountAsync());
}

[Fact]
public async Task SearchByKeywords_ShouldReturnMatches()
{
    var memory = new LongTermMemory();
    await memory.AddEntryAsync(new LongTermMemoryEntry
    {
        Keyword1 = "用户",
        Keyword2 = "喜欢",
        Keyword3 = "猫",
        Description = "用户喜欢猫",
        Importance = 80
    });
    var results = await memory.SearchByKeywordsAsync(new List<string> { "猫" });
    Assert.NotEmpty(results);
    Assert.Contains(results, r => r.Description.Contains("猫"));
}

[Fact]
public async Task GetEntriesByImportance_ShouldFilter()
{
    var memory = new LongTermMemory();
    await memory.AddEntryAsync(new LongTermMemoryEntry { Keyword1 = "a", Importance = 30 });
    await memory.AddEntryAsync(new LongTermMemoryEntry { Keyword1 = "b", Importance = 80 });
    var high = await memory.GetEntriesByImportanceAsync(70);
    Assert.Single(high);
}

[Fact]
public async Task Clear_ShouldResetCount()
{
    var memory = new LongTermMemory();
    await memory.AddEntryAsync(new LongTermMemoryEntry { Keyword1 = "test", Importance = 50 });
    await memory.ClearAsync();
    Assert.Equal(0, await memory.GetCountAsync());
}
```
