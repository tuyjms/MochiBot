# 热重载分析

## 可热重载的配置

| 配置项 | 说明 | 热重载方式 |
|--------|------|-----------|
| ProviderConfig | LLM 提供商/模型 | 重建 LlmClient（已实现） |
| PersonalityConfig | 人格描述/子人格 | 刷新人格缓存（已实现） |
| MaxMessages | 短期记忆容量 | 调整 Capacity（已实现） |
| UserName | 用户名 | 下次对话生效 |
| MurmurEnabled | 碎碎念开关 | 下次定时任务生效 |
| MurmurInterval | 碎碎念间隔 | 下次定时任务生效 |
| Opacity | 窗口透明度 | 立即生效（UI 属性） |
| WindowPos | 窗口位置 | 下次启动生效 |

## 不可热重载的配置

| 配置项 | 原因 |
|--------|------|
| 数据库连接字符串 | 初始化后不可变 |
| 资源路径 | 初始化时确定 |
| 窗口样式/大小 | 需要重建窗口 |
| 事件订阅 | 初始化时注册 |

## 配置修改 UI 设计

- 在 MainWindow 添加一个设置按钮（齿轮图标）
- 点击弹出设置窗口（SettingsWindow）
- 设置窗口包含：
  - 用户名称输入框
  - 透明度滑块
  - 碎碎念开关 + 间隔
  - 保存/取消按钮
- 保存时通过 ConfigReader 写入配置，并发布 ConfigChanged 事件
