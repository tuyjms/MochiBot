# 热重载分析

## 机制概述

`ConfigReader` 是单例，内部缓存 `_cachedAppConfig` / `_cachedModuleSettings` / `_cachedPersonality`。
每次 `Save*()` 方法末尾调用 `Reload()`，清除所有缓存并重新解析 JSON 文件。
`SettingsWindow.SaveButton_Click` 保存后发布 `ConfigChanged` 事件，`Agent.OnConfigChanged` 根据 `changedItems` 列表选择性重建组件。

**核心原则**：配置值是否热重载，取决于消费方是在构造时捕获（snapshot）还是每次使用时从 `ConfigReader.Get*()` 实时读取。

### ProviderConfig

| 配置项 | 热重载方式 | 生效时机 |
|--------|-----------|---------|
| ApiKey | `OnConfigChanged` → 重建 `_chatLlmClient` | 保存后立即 |

### PersonalityConfig

| 配置项 | 热重载方式 | 生效时机 |
|--------|-----------|---------|
| Name / Description | `OnConfigChanged` → 刷新 `_personality` | 保存后立即 |
| Personalities（子人格列表） | `OnConfigChanged` → 刷新 `_currentSubPersonality` | 保存后立即 |
| SystemPromptTemplate | 同上（PersonalityConfig 整体重载） | 保存后立即 |

> **前提**：`changedItems` 包含 `"PersonalityConfig"` 或 `"ActivePersonality"`（SettingsWindow 自动检测）

| 配置项 | 原因 | 影响范围 |
|--------|------|---------|

## ConfigChanged 事件处理流程

```
SettingsWindow.SaveButton_Click()
│
├─ SaveAppSettings()        → Reload() → ConfigChanged("AppSettings")
├─ SaveProviders()          → Reload() → ConfigChanged("ProviderConfig")
├─ SaveModuleSettings()     → Reload() → ConfigChanged("ModuleSettings")
├─ SavePersonality()        → 文件写入 → ConfigChanged("PersonalityConfig")
│
└─ eventDispatcher.Publish(ConfigChanged, changedItems)
    │
    ▼
Agent.OnConfigChanged(eventData)
    ├─ _appSettings = GetAppSettings()                          ← 总是刷新
    ├─ "ProviderConfig"
    │   ├─ 重建 _chatLlmClient
    │   ├─ ResolveFunctionModel + RebuildMemories
    │   └─ RebuildActionExecutor
    ├─ "ActivePersonality"
    │   ├─ 刷新 _personality + _currentSubPersonality
    │   ├─ 重建 _chatLlmClient + _visionService
    │   ├─ ResolveFunctionModel + RebuildMemories
    │   └─ RebuildActionExecutor
    ├─ "PersonalityConfig"
    │   ├─ 刷新 _personality + _currentSubPersonality
    │   └─ 重建 _visionService
    └─ "ModuleSettings"
        ├─ UpdateCapacity(personality.MaxMessages)
        ├─ UpdateOverflowStrategy()
        └─ RestartMaintenanceTimer()
```
