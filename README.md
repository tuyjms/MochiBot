# MochiBot

一个基于 .NET 10.0 的 Windows 桌面桌宠，接入 LLM 实现 AI 对话。用于学习团队合作和闲暇时逗逗桌宠。

## 快速开始

### 前置条件

- [.NET 10.0 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- Git

### 克隆与运行

```bash
git clone https://github.com/tuyjms/MochiBot.git
cd MochiBot
dotnet restore
dotnet run
```

## 运行测试

```bash
dotnet test
```
